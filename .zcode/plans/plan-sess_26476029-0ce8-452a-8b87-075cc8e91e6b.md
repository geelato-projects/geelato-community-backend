# MetaStore 解耦计划：三个方法保留，移除 Dao 参数

## 范围
聚焦 `MetaStore` 一个 SPI：三个方法签名保留，去掉 `Dao` 参数，Dao 由实现者自行注入。`MetaManager` 不再持有 `this.dao`。`MetaBootstrap` 本次不动（保留 Dao 参数），因此两个引导配置类保留 `private Dao dao` 字段仅供 bootstrap 使用。

---

## 改动清单

### A. SPI 接口（geelato-core）
1. **`meta/spi/MetaStore.java`**：三个方法去掉 `Dao dao` 参数，删 `import ...orm.Dao`：
```java
public interface MetaStore {
    MetaDefinitionBundle load(Map<String, String> params);
    MetaDefinitionBundle loadByEntityName(String entityName);
    MetaDefinitionBundle loadByViewName(String viewName);
}
```

### B. 唯一实现（geelato-web-platform）
2. **`core/meta/support/DefaultMetaStore.java`**：
   - 新增构造器注入：`private final Dao dao;` + `public DefaultMetaStore(@Qualifier("primaryDao") Dao dao)`（沿用本模块惯例）。
   - 三个 `@Override` 方法去掉 `Dao dao` 形参，方法体内 `dao` 改为 `this.dao`，SQL 调用逻辑原样不变。

### C. 管理器（geelato-core）
3. **`meta/MetaManager.java`**：
   - 删字段 `private Dao dao;`（行 55）与 `import ...orm.Dao;`（行 18）
   - `parseDBMeta(Dao dao)` → `parseDBMeta()`；`parseDBMeta(Dao dao, Map params)` → `parseDBMeta(Map params)`；删两处 `this.dao = dao;`
   - 三处调用去 dao 实参：
     - 行 131 `metaStore.load(dao, params)` → `metaStore.load(params)`
     - 行 188 `metaStore.loadByViewName(dao, viewName)` → `metaStore.loadByViewName(viewName)`
     - 行 201 `metaStore.loadByEntityName(dao, entityName)` → `metaStore.loadByEntityName(entityName)`
   - `if (metaStore == null) { skip; return; }` 防御逻辑保留（框架层无 DB 仍可跑）。

### D. 引导配置层（保留 dao 字段，仅改 parseDBMeta 调用）
4. **`web/platform/boot/MetaConfiguration.java`**：`metaManager.parseDBMeta(dao);` → `metaManager.parseDBMeta();`（`private Dao dao` 字段保留供 `metaBootstrap.bootstrap(metaManager, dao)` 使用）。
5. **`mcp/platform/config/MetaInitConfig.java`**：`metaManager.parseDBMeta(dao);` → `metaManager.parseDBMeta();`（判据 `if (dao != null)` 与 bootstrap 调用保留不动）。

### E. 业务调用点
6. **`srv/platform/service/MetaDdlService.java`** 行 205/276/417：`metaManager.parseDBMeta(primaryDao, table);` → `metaManager.parseDBMeta(table);`（保留 table 实参）。

### 不改动
- `MetaBootstrap.java`（保留 Dao 参数）。
- 17 处 `refreshDBMeta(String)`、4 处 `getByEntityName(name, false)`、2 处 `setMetaStore` 调用 —— 签名未变。

---

## 验证
1. `mvn -q -T 1C -DskipTests compile`（geelato-core / geelato-web-platform / geelato-mcp-platform / geelato-web-designer）。
2. `grep -rn "Dao" geelato-core/.../meta/spi/MetaStore.java` 应无输出；`grep -n "Dao" MetaManager.java` 应无输出。

## 风险
- **低**：`MetaStore` 仅 1 个实现，签名变更完全可控；`MetaBootstrap` 不动，引导配置类改动最小。
