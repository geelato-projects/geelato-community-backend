# DSL 查询结果自动推断优化(形状推断 + Class 重载,支持自定义类)

## 目标写法

```java
// 1. 无参自动推断:单列查询未设 wrapperResult 时,自动返回裸值(不做类型转换)
List<String> emails = MetaFactory.sql("SELECT email_address FROM platform_user_email_account WHERE user_id = ?")
        .param(userId)
        .list();

// 2. Class 重载 - 简单类型:单列 + 类型转换
List<Integer> ages = MetaFactory.sql("SELECT age FROM platform_user WHERE ...").param(id).list(Integer.class);

// 3. Class 重载 - 自定义类:行 Map 直接映射成 DTO(替代现有 wrapperResult 里手写 JSON 转换的惯用法)
List<UserOrgDto> orgs = MetaFactory.sql("SELECT o.id, o.name, oru.default_org FROM ... WHERE u.id = ?")
        .param(userId)
        .list(UserOrgDto.class);          // 不再需要 .wrapperResult(this::toUserOrg)

UserOrgDto org = MetaFactory.sql("SELECT ... WHERE u.id = ? LIMIT 1").param(userId).one(UserOrgDto.class);
```

说明:Java 泛型擦除下无参 `list()` 无法感知声明类型(R 运行期不存在),自动推断依据是**结果集形状**(每行仅一列→裸值);显式类型需求由 Class 重载承担,并支持自定义 DTO。

## 类型规则(Class 重载)

传入的 `Class<R>` 按以下顺序判定:

| 类型 | 行为 |
|---|---|
| `Map.class`/Map 子类 | 行 Map 原样返回 |
| 简单类型(String、Boolean、Character、Number 及包装类/原子类型、Date、java.time.*) | 要求单列(多列抛 IllegalArgumentException,消息含实际列名),逐值转换:Number↔Number 用 Spring `NumberUtils.convertNumberToTargetClass`,目标 String 用 String.valueOf |
| 其他(自定义 DTO/实体类) | `JSON.parseObject(JSON.toJSONString(row), type)`(fastjson2,已在 orm 依赖树上,`BoundSqlJdbcSupport` 即在用),支持 snake_case 列名→camelCase 字段 smart-match、Enum 转换 |
| 行为 null/空 | 返回 null |

优先级:设置了 `wrapperResult` 时仍优先走 wrapper(全规则统一);未设置时才走自动解包/Class 映射。

## 改动清单

### 1. 新增 `geelato-orm/src/main/java/cn/geelato/orm/support/QueryResultMapper.java`

静态工具类,集中三类逻辑:
- `unwrapSingleColumn(Map)` / `unwrapSingleColumn(List<Map>)` — row.size()==1 取裸值,否则原样返回(供无参 list/one/page 自动推断)
- `isSimpleType(Class)` — 简单类型白名单判定
- `convertValue(Object, Class)` — 简单类型值转换(null→null;isInstance 直返;数值/字符串互转;不支持抛 IllegalArgumentException)
- `mapRow(Map<String,Object>, Class<R>)` / `mapRows(List<Map<String,Object>>, Class<R>)` — 按上表规则分发

### 2. 三个构建器统一改造

- **`MetaNativeSql.java`**:
  - `list()`/`one()` 的 `wrapperFunction == null` 分支改用 `unwrapSingleColumn`
  - 新增 `list(Class<R> elementType)`、`one(Class<R> elementType)`(wrapperFunction 非空时先 apply 再按 Class 映射;one 无行→null,与现有语义一致)
- **`MetaQuery.java`**:`list()`/`one()`/`page()`(records 重建 PageResult,参照现有 wrapper 分支)同样接入;新增 `list(Class)`/`one(Class)`;`oneColumn(Class)` 保留(执行器层单列专径,职责不冲突)
- **`MetaProcedure.java`**:`list()`/`one()` 接入自动解包;新增 `list(Class)`/`one(Class)`

### 3. 存量单列+Map 用法同步迁移(否则新行为下取元素时 CCE)

- `WeixinWorkService.java` 3 处(L15-19、L43-47、L50-54)简化为:
  ```java
  Object value = MetaFactory.sql("SELECT weixin_work_info FROM platform_company WHERE org_id = ?")
          .param(orgId).one();
  return value == null ? null : value.toString();
  ```
- `ReportConfigEditorDatabaseService.resolveCustomerConfigId`(L218-225,`SELECT id` 单列)同理改裸值(对齐现 asString(row,"id") 语义,实现时核对 asString)
- 可选顺手简化:`UserIdentityQueryService`/`NoticeOrmService`/`TenantOrmService`/`DictionaryController`/`EmailAccountController` 中"JSON 往返式 wrapperResult"改为 `.list(Dto.class)`(如 toNotice/toTenant 即 `JSON.parseObject(JSON.toJSONString(row), X.class)`,语义完全等价);手工 setter 式 wrapper(如 toUserOrg)保持不动

### 4. 文档更新(3 个文件)

`docs/orm/backend-fluent-dsl-guide.md`(L231-236 单列 wrapperResult 示例改为 `.list()`;DTO 示例补 `.list(Dto.class)`)、`website/i18n/en/docusaurus-plugin-content-docs/current/orm/fluent-dsl.md`、`website/official-docs/zh-cn/orm/fluent-dsl.md`。说明:单列自动返回裸值(不转换)、`list(Class)`/`one(Class)` 类型规则(简单类型转换/自定义类映射/Map 原样)、想要 Map 用身份 wrapper `.wrapperResult(row -> row)`、推断依据是结果集列数(泛型擦除限制)。

### 5. 新增测试 `geelato-orm/src/test/java/cn/geelato/orm/MetaResultMappingTest.java`

测试基建:Mockito 模拟 `ApplicationContext`(`getBean(OrmRuntimeProvider.class)` 返回持有 mock Dao 的 `DefaultMetaCommandExecutor`),`new BeansUtils().setApplicationContext(mockCtx)` 注入后跑 `MetaFactory.sql(...)` 全链路。

用例:
1. 自动解包:单列 `list()`→`List<String>` 裸值;单列 `one()`→裸值;多列照旧返回 Map(回归);空结果→空列表/null;单列值 null→null 元素
2. wrapperResult 优先:设置后不走自动解包
3. Class 重载-简单类型:`list(String.class)` Long 列→String;`list(Integer.class)` 数值转换;多列+简单类型→IllegalArgumentException;`one(String.class)` 无行→null
4. Class 重载-自定义类:多列行→DTO 字段填充(含 snake_case 列名→camelCase 字段);空结果→空列表;`one(Dto.class)` 无行→null(测试 DTO 用带公有字段/setter 的普通类,确保 fastjson2 可实例化)
5. Class 重载-Map:`list(Map.class)` 原样(回归保护)
6. MetaQuery 单字段 `select(...)` 的 `list()` 裸值 + `list(Dto.class)` 映射(若元数据环境搭建成本过高,至少覆盖 MetaNativeSql 全量用例)
