# 错误码定义内聚到异常类（常量直写，无枚举/注解）

## 目标

删除 GlobalErrorCodes 枚举与 ErrorCode 接口，错误码以**类内常量 + 构造器直写**的形式定义在每个异常类中——最简形态，零外部机制。码值沿用现状不变（前端零影响）。

## 一、CoreException 极简化（geelato-lang）

```java
public abstract class CoreException extends RuntimeException {
    private final int errorCode;

    public CoreException(int errorCode, String msg) { ... }
    public CoreException(int errorCode, String msg, Throwable cause) { ... }

    public int getErrorCode() { return errorCode; }
    public String getErrorMsg() { return getMessage(); }
    public int getHttpStatus() { return 500; }   // 默认；仅鉴权类覆写
    public String getDocSlug() { return null; }  // 默认；仅 SqlExecuteException 覆写
    public String getUserMessage() { return getErrorMsg(); }  // SqlExecuteException 覆写分类文案
}
```
- httpStatus / docSlug 用**可覆写方法**而非构造参数：全平台只有 3 个鉴权类（401/400/403）和 1 个 docSlug 覆写点，其余子类零额外代码
- 删除 ErrorCode 接口、GlobalErrorCodes 枚举

## 二、异常类形态（码值不变）

```java
public class UnauthorizedException extends CoreException {
    public static final int ERROR_CODE = 20001;

    public UnauthorizedException() { this("未授权访问，请重新登录"); }
    public UnauthorizedException(String message) { super(ERROR_CODE, message); }

    @Override public int getHttpStatus() { return 401; }
}
```
- 19 个子类全部改为该形态：码值常量 + 构造器直写文案；无参构造传默认文案（即用户文案）
- 3 个鉴权类覆写 getHttpStatus（401/400/403）；SqlExecuteException 覆写 getDocSlug() 返回 "sql-execute"，保留 getUserMessage() 分类覆写
- `FileException`：删除泛型构造器；二级子类 detailMessage 构造直接拼 `"文件类型不支持：" + detailMessage`
- `LoginMultiTenantException.DEFAULT_CODE = 20005`（直接写值，JWTAuthController 引用不变）
- SYSTEM_BUSY 无异常类需求消失：兜底 handler 直接用 `PlatformErrorResult` 已有的 `(int, String)` 构造器 `new PlatformErrorResult(50001, "系统繁忙，请稍后重试")`
- `PLUGIN_LOAD_FAILED`(40005) 随枚举消失（文档注明段位空缺）

## 三、适配（geelato-web-platform）

- `PlatformExceptionHandler.resolveHttpStatus()`：改用 `ex.getHttpStatus()`；兜底分支用 `PlatformErrorResult(50001, ...)`，其 msg/文案取值同步改为常量直写
- `PlatformErrorResult`：删除 `(ErrorCode)` 构造器与 ErrorCode import；`(CoreException)` 构造器不变（getUserMessage/ getErrorCode 均在）
- `ErrorDocResolver.resolve()`：改用 `ex.getDocSlug()` / `ex.getErrorCode()`
- `ApiResult.exception()`：取 `getErrorCode()`，天然兼容不动

## 四、测试与文档

- `PlatformExceptionHandlerTest`：匿名 CoreException 用法改为 `AuthBadRequestException` 实例（匿名子类已无法构造——CoreException 构造器需显式码值，属预期行为）；码值断言不变
- `error-codes.md`：治理规则改为"错误码以 `ERROR_CODE` 常量定义在各异常类内，本页码表为登记清单；新增码在对应类别段顺延并更新本页"；码表值不变
- 码值重复无编译期/运行期强制检测（按用户决定），文档锚点 + 本页登记表为事实源
