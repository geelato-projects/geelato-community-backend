应用与平台配置（platform）

13 个 Controller，共 80 个端点。标注 ⚙ 的为设计态接口。

AppController — /app​

应用注册与版本包导入、按用户身份过滤可见应用、应用页面权限查询。

pageQuery 分页查询​

项内容
URLPOST /api/app/pageQuery
参数分页与过滤参数见公共约定
返回ApiPagedResult：data 为应用（App）分页数据。

query 列表查询​

项内容
URLGET /api/app/query
参数分页与过滤参数见公共约定
返回ApiResult<List<App>>：应用列表。

queryByUser 按用户查应用​

项内容
URLGET /api/app/queryByUser
参数tenantCode：query，string，必填，租户编码。
userId：query，string，可选，用户 ID，缺省取当前登录用户。
返回ApiResult<List<Map<String,Object>>>：data 为该用户可见的应用列表，按用户类型过滤：员工/虚拟员工仅见普通应用（企业内部或企业内外部），租户管理员与系统可见普通及平台应用，企业外部人员仅见企业外部普通应用。

get 查询详情​

项内容
URLGET /api/app/get/{id}
参数id：path，string，应用 ID。
返回ApiResult<App>：应用详情。

createOrUpdate 新建或更新​

项内容
URLPOST /api/app/createOrUpdate
参数form：body，App 实体；id 非空更新、为空新建。
useType：query，string，可选；取值 import 时走导入流程（要求 form.id 非空，按已有 ID 导入应用）。
返回ApiResult<App>：保存或导入后的应用。

isDelete 删除应用​

项内容
URLDELETE /api/app/isDelete/{id}
参数id：path，string，应用 ID。
返回ApiResult<NullResult>：data 为空；应用不存在时报错（软删除）。

validate 校验唯一性​

项内容
URLPOST /api/app/validate/{type}
参数type：path，string，校验类型：code 校验应用编码可用性、id 校验应用 ID 是否已存在。
form：body，App 实体，提供待校验的 code、id、tenantCode。
返回ApiResult<Boolean>：true 表示可用（编码未被占用或 ID 不存在）；type 非法时返回失败。

queryPermissionByPage 应用页面权限查询​

项内容
URLGET /api/app/queryPermissionByPage
参数appId：query，string，可选，按应用过滤。
tenantCode：query，string，可选，按租户过滤。
type：query，string，可选，权限类型。
treeId：query，string，可选，应用页面树节点 ID。
返回ApiResult<List<Map<String,Object>>>：data 为页面权限记录列表（权限 ID、名称、编码、类型、对象、规则及所属页面树节点 ID）。

queryRolePermissionByPage 角色页面权限查询​

项内容
URLGET /api/app/queryRolePermissionByPage
参数appId：query，string，可选，按应用过滤。
roleId：query，string，可选，角色 ID，支持逗号分隔多个。
type：query，string，可选，权限类型。
tenantCode：query，string，可选，按租户过滤。
返回ApiResult<List<Map<String,Object>>>：data 为角色与页面权限关联记录（角色、权限及所属应用）。

upload 上传应用包​

项内容
URLPOST /api/app/upload/{fileId}
参数fileId：path，string，已上传的应用包附件 ID（.gdp 压缩包）。
返回ApiResult<App>：data 为导入/更新后的应用；包内需含 .gdp 描述文件（源应用 ID、名称、编码、版本），文件不存在或解析失败时报错。

BizDataController — /bizData​

业务数据归属者批量移交：跨实体修改创建人等归属字段。

changeOwner 批量移交数据归属​

项内容
URLPOST /api/bizData/changeOwner
参数entityIdMap：body，Map<String,List<String>>，键为实体名称，值为该实体待移交的主键 ID 列表。
owner：query，string，必填，目标归属用户 ID。
返回ApiResult<Map<String,Integer>>：data 为各实体成功更新的记录数。管理员可移交任意非平台实体的数据；非管理员仅能移交自己创建的数据，且实体须含归属字段；平台类实体（platform 目录/实体名/表名前缀）禁止移交；存在越权记录、非法实体或未知用户时整体失败并附拒绝明细。

参数form：body，CustomSql 实体；id 非空更新、为空新建；保存前执行字段预处理（afterSet）。
返回ApiResult<CustomSql>：保存后的自定义 SQL。

isDelete 删除 SQL​

项内容
URLDELETE /api/sql/isDelete/{id}
参数id：path，string，SQL ID。
返回ApiResult<NullResult>：data 为空。

validate 校验键可用性​

项内容
URLPOST /api/sql/validate
参数form：body，CustomSql 实体，提供待校验的 keyName、id、appId、tenantCode。
返回ApiResult<Boolean>：true 表示 keyName 可用。

refresh 刷新 SQL 缓存​

项内容
URLGET /api/sql/refresh/{sqlKey}
参数sqlKey：path，string，SQL 脚本 key。
返回ApiResult<NullResult>：data 为空；按 key 刷新已注册的 SQL 脚本缓存。

queryByApp 按应用查 SQL​

项内容
URLGET /api/sql/query/{appId}
参数appId：path，string，应用 ID。
返回ApiResult<List<CustomSql>>：data 为该应用的自定义 SQL，以及其他应用授权（启用且审批同意）给该应用的 SQL 合并列表。

URLGET /api/sys/config/query

createOrUpdate 新建或更新​

URLPOST /api/sys/config/createOrUpdate

返回ApiResult<SysConfig>：保存后的配置；启用状态的配置保存后刷新环境配置缓存。

isDelete 删除配置​

项内容
URLDELETE /api/sys/config/isDelete/{id}
参数id：path，string，配置 ID。
返回ApiResult<NullResult>：data 为空；删除并将配置置为停用。

validate 校验键可用性​

项内容
URLPOST /api/sys/config/validate
参数form：body，SysConfig 实体，提供待校验的 configKey、id、tenantCode。
返回ApiResult<Boolean>：true 表示 configKey 可用。

getValue 按键取值​

项内容
URLGET /api/sys/config/getValue/{key}
参数key：path，string，配置键。
返回ApiResult<String>：data 为启用状态配置的值；无匹配配置时为空字符串。
