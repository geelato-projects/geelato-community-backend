安全与权限（security）

19 个 Controller，共 125 个端点。标注 ⚙ 的为设计态接口。

AccountController — /sys/account​

用户自助注册账号。

create 注册账号​

项内容
URLPOST /api/sys/account
参数user：body，User 实体，注册用户的账号信息。
返回ApiResult<NullResult>：data 为空，仅表示注册是否成功。

AuthCodeController — /code​

验证码生成与发送：按验证方式（短信/邮箱）生成 6 位验证码，发送消息并写入 Redis 缓存。

generateUser 生成用户验证码​

项内容
URLPOST /api/code/generate/user
参数body：Map<String,Object>，字段映射到 AuthCodeParams：userId（用户 ID，用户须已存在）、action（业务动作，如 VALIDATEUSER）、validType（验证方式：手机/邮箱）、prefix（手机前缀）、validBox（手机号或邮箱，action 为 VALIDATEUSER 时从用户资料回填）、authCode（验证码）。
返回ApiResult<NullResult>：data 为空；失败时 msg 带错误信息。

generateAuth 生成鉴权验证码​

项内容
URLPOST /api/code/generate/auth
参数body：Map<String,Object>，字段同上；直接按 validType 向 validBox（手机/邮箱）发送验证码并写入缓存。
返回ApiResult<NullResult>：data 为空；失败时 msg 带错误信息。

EncodingController — /encoding​

编码规则管理与编码值生成（单据号、序列号等）。

pageQuery 分页查询​

项内容
URLPOST /api/encoding/pageQuery
参数分页与过滤参数见公共约定
返回ApiPagedResult：data 为编码规则（Encoding）分页数据。

query 列表查询​

项内容
URLGET /api/encoding/query
参数分页与过滤参数见公共约定
返回ApiResult<List<Encoding>>：编码规则列表。

get 查询详情​

项内容
URLGET /api/encoding/get/{id}
参数id：path，string，编码规则 ID。
返回ApiResult<Encoding>：编码规则详情。

createOrUpdate 新建或更新​

项内容
URLPOST /api/encoding/createOrUpdate
参数form：body，Encoding 实体；id 为空新建、非空更新。
返回ApiResult<Encoding>：保存后的编码规则；保存后同步刷新编码缓存。

isDelete 删除规则​

项内容
URLDELETE /api/encoding/isDelete/{id}
参数id：path，string，编码规则 ID。
返回ApiResult<NullResult>：data 为空；删除后同步清理编码缓存。

generate 生成编码值​

项内容
URLPOST /api/encoding/generate/{id}
参数id：path，string，编码规则 ID。
argumentParam：query，Map<String,Object>，生成编码所需参数（使用系统编码 app 时需传 appId）。
body：Map<String,Object>，可选，额外参数，键值优先级高于 query 参数。
返回ApiResult<String>：data 为按规则生成的新编码值。

OnlineUserController — /online​

在线用户查询（基于 Redis 记录的活跃名单）。

list 在线用户列表​

项内容
URLGET /api/online/list
参数windowMinutes：query，int，可选，统计时间窗（分钟），缺省取系统默认值。
limit：query，int，可选，返回条数上限，缺省取系统默认值。
仅管理员可调用，非管理员返回失败。
返回ApiResult<List<OnlineUserInfo>>：data 为在线用户信息列表（用户 ID、登录名、姓名、租户、组织、最后活跃时间等）。

项内容
URLPOST /api/security/user/pageQueryStock

返回ApiPagedResult：data 为用户分页数据并联查应用/租户下的角色；无结果时为用户列表，有结果时为 {role: 角色列表, table: 用户行列表（每行含用户字段及各角色 ID 的勾选布尔值）} 结构。
