接口与编排授权

本页覆盖接口服务、自定义编排、导出模板与应用授权关系共 7 个实体。Api 定义应用对外暴露的服务接口；CustomSql 是无代码的接口编排；三个 App*Map 关联表把应用与模型、视图、编排授权起来；ExportTemplate 支撑文件导出。

Api 服务接口​

应用对外暴露的服务接口定义：MQL/编排/JS 脚本等形式的接口，含匿名访问、分页、第三方开放等控制。继承 BaseEntity，公共字段见概览。

属性列名类型说明
appIdapp_idString所属应用
namenameString名称
codecodeString编码
pagingpagingboolean是否分页，默认 false
methodmethodString请求方法
remarkremarkString备注
versionversionInteger版本
anonymousanonymousint是否匿名访问：1 允许匿名不鉴权、0 不允许匿名需鉴权，默认 0。有 enable_status 字段但未实现 EntityEnableAble 接口
groupNamegroup_nameString分组名称
enableStatusenable_statusint是否启用：0 禁用、1 启用，控制接口可访问性，默认 1
sourceContentsource_contentStringGlPage 的组件树字符串
releaseContentrelease_contentString生成的可执行 JavaScript 脚本
outsideUrloutside_urlString第三方访问地址
outsideStatusoutside_statusint第三方访问状态，默认 0
responseFormatresponse_formatString响应格式
responseTyperesponse_typeString响应参数类型
logLevellog_levelString日志级别
requestParams—List<ApiParam>@Transient 非落库，请求参数树，见 ApiParam
responseParams—List<ApiParam>@Transient 非落库，响应参数树，见 ApiParam

ApiParam 接口服务参数​

接口的入参/出参定义，按 pid 组成参数树。继承 BaseEntity。

属性列名类型说明
appIdapp_idString所属应用
apiIdapi_idString所属接口
pidpidString父参数 id，构成参数层级
paramTypeparam_typeString参数类型（请求/响应归类）
bodyTypebody_typeString类型
namenameString名称
dataTypedata_typeString参数数据类型
defaultValuedefault_valueString参数默认值
demoValuedemo_valueString示例数据
alternateTypealternate_typeString交互类型
requiredrequiredboolean是否必填，默认 false
jacketjacketboolean源码无注释，默认 false
remarkremarkString备注
children—List<ApiParam>@Transient 非落库，子参数树

CustomSql 自定义接口编排​

无代码的接口编排定义（platform_sql），声明请求/响应参数与编排内容，键名即调用标识。继承 BaseEntity。有 enable_status 字段但未实现 EntityEnableAble 接口。

属性列名类型说明
appIdapp_idString所属应用
titletitleString标题
keyNamekey_nameString键名称
requestParamsrequest_paramsString请求参数
responseTyperesponse_typeString响应参数类型
responseParamsresponse_paramsString响应参数
descriptiondescriptionString描述
enableStatusenable_statusint是否启用：0 停用、1 启用
configTypeconfig_typeString配置类型
encodingContentencoding_contentString编码内容，保存时若为 base64 data URI 则自动解码（afterSet）

AppSqlMap 应用接口编排关系表​

应用与接口编排（CustomSql）的授权关系。类级标题"应用接口编码关系表"中的"编码"指接口编排（sqlKey/sqlTitle 均指向 CustomSql）。继承 BaseEntity。有 enable_status 字段但未实现 EntityEnableAble 接口。

属性列名类型说明
appIdapp_idString申请应用主键
appNameapp_nameString申请应用名称
sqlIdsql_idString接口编排主键，指向 CustomSql
sqlTitlesql_titleString接口编排标题
sqlKeysql_keyString接口编排键名称
sqlAppIdsql_app_idString接口编排所属应用
approvalNeedapproval_needboolean是否需要审批，默认 false
approvalStatusapproval_statusString审批状态
enableStatusenable_statusint是否启用：0 停用、1 启用
descriptiondescriptionString描述

ExportTemplate 导出文件模板​

导出文件模板定义：按文件类型与用途配置模板，最多 19 个模板槽位（indexTemplate 按 1~19 取用），并携带业务数据类型、清洗规则、元数据与可视化布局 JSON。继承 BaseEntity，实现 EntityEnableAble。注意：该实体源码字段级 @Title 大面积复制粘贴为"状态"，下表按字段名与行内注释的实际语义撰写。

属性列名类型说明
appIdapp_idString所属应用（源码 @Title 误写"状态"）
titletitleString模板标题（源码 @Title 误写"状态"）
useTypeuse_typeString用途
fileTypefile_typeString文件类型
fileCodefile_codeString文件编码
templatetemplateString模板内容，槽位 1
templateRuletemplate_ruleString模板规则
enableStatusenable_statusint状态：0 停用、1 启用
descriptiondescriptionString描述
businessTypeDatabusiness_type_dataString数据类型
businessRuleDatabusiness_rule_dataString清洗规则
businessMetaDatabusiness_meta_dataString元数据
canvasLayoutDatacanvas_layout_dataStringWYSIWYG 可视化布局 JSON
template2~template19template2~template19String模板槽位 2~19，经 indexTemplate(index) 按索引取用
