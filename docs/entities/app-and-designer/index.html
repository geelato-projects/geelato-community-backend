应用与设计器

本页覆盖应用定义、版本管理、页面协作与多语言、菜单导航共 8 个实体。应用（App）是低代码平台的聚合根，页面（AppPage）是设计器的核心产出；页面通过签入签出机制多人协作；多语言实体承载应用与页面的国际化文案；TreeNode 与 MenuItem 承载导航。

App 应用​

低代码应用定义，平台的聚合根：前端运行时按应用加载页面、菜单与主题。继承 BaseSortableEntity，公共字段见概览。

属性列名类型说明
namenameString应用名称
codecodeString编码
typetypeString应用分类
iconiconString图标
appKeyapp_keyString应用秘钥
tokentokenString应用 Token
treetreeString文件树，JSON 字符串（如 jsTree）
logologoStringLogo
themethemeString应用主题
watermarkwatermarkint应用水印，是否启用水印，默认不启用
hrefhrefString首页链接，加载模块之后打开的首页面
dependAppCodedepend_app_codeString依赖的应用模块编码，可多个，格式如 dev,sys
powerInfopower_infoString权限信息，页面底部的网站说明
versionInfoversion_infoString版本信息
descriptiondescriptionString描述
applyStatusapply_statusint应用站点状态：1 启用、0 禁用
designStatusdesign_statusint设计站点状态：1 启用、0 禁用
appStorageapp_storageString应用仓库地址
purposepurposeString应用范围
ideVersionide_versionStringIDE 版本
modelColumnPclmodel_column_pclString模型字段权限校验级别：strict 严格、loose 宽松
roles—String@Transient 非落库，查询辅助字段

AppVersion 应用版本​

应用版本管理，记录每次打包产物的地址与状态。继承 BaseEntity。与应用打包流程的关系见应用打包。

属性列名类型说明
packagePathpackage_pathString包地址
versionversionString版本名称
packageSourcepackage_sourceString包来源
appIdapp_idString所属应用
packetTimepacket_timeDate打包时间
statusstatusString状态
descriptiondescriptionString描述

AppPage 页面​

页面设计器产出的页面定义，源码、预览、发布三态内容分列存储；签入签出字段支撑多人协作。继承 BaseSortableEntity。

属性列名类型说明
extendIdextend_idString扩展信息，扩展 id，如对应的叶子节点 id
appIdapp_idString应用 Id，所属应用
typetypeString类型，如 api/form/table
titletitleString标题
codecodeString编码
sourceContentsource_contentString源文件内容，longText，非空
previewContentpreview_contentString预览的内容，longText，非空
releaseContentrelease_contentString发布的内容，longText，非空
descriptiondescriptionString描述
versionversionint版本
checkUserIdcheck_user_idString签入用户 ID
checkUserNamecheck_user_nameString签入用户名
checkStatuscheck_statusString签入状态：unchecked（未签出）、checkedOut（已签出），对应 CheckStatusEnum
checkAtcheck_atDate签入时间

AppPageCheckReq 页面签出申请接管请求​

页面签出申请/接管请求实体：页面被他人签出时，通过本实体发起接管申请并跟踪审批。继承 BaseEntity。

属性列名类型说明
pageIdpage_idString页面 ID，非空
pageTitlepage_titleString页面标题，非空
requesterIdrequester_idString发起用户 ID，非空
requesterNamerequester_nameString发起用户名称，非空
targetUserIdtarget_user_idString目标用户 ID（当前签出人），非空
targetUserNametarget_user_nameString目标用户名称，非空
requestTimerequest_timeDate请求时间，非空
statusstatusString请求状态：pending/approved/rejected/expired，非空
processTimeprocess_timeDate处理时间
processUserIdprocess_user_idString处理用户 ID
processUserNameprocess_user_nameString处理用户名称
processCommentprocess_commentString处理备注，varchar(500)

AppMultiLang 应用多语言​

应用级多语言文案：一种语言一行语言包。继承 BaseEntity。有 enable_status 字段（未实现 EntityEnableAble 接口）。

属性列名类型说明
appIdapp_idString应用 ID
langTypelang_typeString语言类型
langPackagelang_packageString语言包
purposepurposeString语言范围
enableStatusenable_statusint启用状态：1 启用、0 未启用

AppPageLang 页面多语言​

页面级多语言文案，按页面版本存储。继承 BaseEntity。

属性列名类型说明
pageIdpage_idString所属页面
versionversionint版本
langTypelang_typeString语言类型
contentcontentString多语言内容
extendIdextend_idString菜单树节点 ID
appIdapp_idString所属应用

TreeNode 菜单​

通用树节点实体，类级标题"菜单"：既承载运行时菜单树，也承载设计器文件树等任意业务树（由 treeEntity/treeId 挂接归属）。继承 BaseSortableEntity。

属性列名类型说明
treeEntitytree_entityString树实体：节点所属树对应的业务实体，如项目文件树对应 platform_project
treeIdtree_idString树 Id：树对应业务实体某条记录的 id，如项目 id，非空
pidpidString父节点 Id，字符串格式，解决数字类型太大在 Web 端展示失真
typetypeString节点类型
iconiconString节点图标
texttextString节点标题
iconTypeicon_typeString节点图标类型
extendEntityextend_entityString扩展实体，如叶子节点对应的文件表名、业务表名
extendIdextend_idString扩展实体 ID，如叶子节点对应的文件 id、表单 id
metametaString节点扩展元信息，JSON 格式字符串
flagflagString标志旗，对节点做特别标识，如该节点作为菜单项
urlurlString链接，通过菜单项打开第三方链接
descriptiondescriptionString描述

MenuItem 菜单项​

菜单项与菜单子项定义，可链接设计器页面或树节点。继承 BaseSortableEntity。

属性列名类型说明
titletitleString标题
clazzclazzString样式类
activeactiveString激活
linkTypelink_typeString链接类型：dynamicPage（设计器配置的页面）或 other，长度 20
hrefhrefString链接
pageCodepage_codeString链接页面，链接打开的页面编码
treeNodeIdtree_node_idString树节点 id，关联 TreeNode
