全平台实体索引

本页是平台全部运行期实体的总索引：回答"平台到底存在哪些实体元数据"。平台实体的定义分布在多个模块——核心实体集中在 geelato-meta，特性模块（业务告警、业务异常、邮件、平台内置能力）各自定义自己的实体，注册机制相同：都在 cn.geelato 包下，由 MetaManager 启动扫描自动注册（见概览）。

不纳入本索引的"实体"：

  • 框架元数据模型类（geelato-core 的 TableMeta、ColumnMeta、TableView、TableCheck、TableForeign、ConnectMeta）——它们虽也标注 @Entity，但承载的是"元数据的定义"本身，映射到 platform_dev_* 设计器六表，见元数据说明。
  • geelato-maintenance 的 MqlTest* 样例模型（MqlTestUser/MqlTestOrder/MqlTestOrderItem 等）——MQL 测试夹具，非运行期实体。
