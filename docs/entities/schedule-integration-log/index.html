调度集成与日志

本页覆盖调度任务、ORM 钩子与各类日志共 7 个实体。OrmHook + OrmHookLog 构成"配置 + 发件箱"的实体事件外推机制；Schedule + ScheduleLog 构成定时调度对；EncodingLog 是单据编码/流水号生成记录；AppPageLog 与 PlatformExceptionLog 分别是页面操作与平台错误日志。

Schedule 调度任务​

定时调度任务定义：cron 表达式驱动，支持 java 类型任务与参数、重试、持久化上下文。类级标题误写为"应用"，按实际语义撰写。继承 BaseEntity，公共字段见概览。调度引擎视角见调度模块。

属性列名类型说明
appIdapp_idString所属应用
namenameString名称
codecodeString编码
classInfoclass_infoStringtype=java 时为"类名，方法名"
expressionexpressionStringcron 表达式
typetypeString类型
paramsparamsString参数
statusstatusInteger状态：0 停止、1 启动，默认 0
descriptiondescriptionString描述
retryTimesretry_timesInteger重试次数
extraextraString冗余字段
lastStartTimelast_start_timeDate上次任务开始时间
lastFinishTimelast_finish_timeDate上次任务结束时间
contextcontextString任务持久化上下文

OrmHook ORM实体钩子配置​

ORM 实体钩子配置：一条 Hook = 名称 + 地址 + 启停。平台内任何实体的 insert/update/delete 事务提交后，向地址 POST 完整载荷 JSON（entityName/eventType/values），下游自行分发处理。纯附加特性：业务事务内零额外操作，触发与执行全部异步，经发件箱 platform_orm_hook_log 重试/死信，失败永不上抛；钩子机制自身的两张表不触发（防递归）。继承 BaseEntity。

属性列名类型说明
titletitleString钩子名称，非空，长度 128
httpUrlhttp_urlString地址，下游系统接收 POST 的 URL，非空，长度 512
enableStatusenable_statusint是否启用：0 禁用、1 启用，默认 1

AppPageLog 页面操作日志​

页面（设计器）操作日志，保存页面源文件内容快照。继承 BaseEntity。

属性列名类型说明
appIdapp_idString应用 Id，所属应用
pageIdpage_idString页面 Id，关联的页面
codecodeString编码
labellabelString标题
typetypeString类型，如 api/form/table
versionversionint版本
extendIdextend_idString扩展信息，扩展 id（如对应的叶子节点 id）
descriptiondescriptionString描述
sourceContentsource_contentString源文件内容，longText，非空

ScheduleLog 调度日志​

调度任务执行日志，一次执行一行。继承 BaseEntity。

属性列名类型说明
appIdapp_idString所属应用
scheduleIdschedule_idString所属调度 ID
scheduleCodeschedule_codeString调度编码
scheduleNameschedule_nameString所属调度名称
scheduleInfoschedule_infoString调度信息：表达式、参数、重试次数
typetypeString类型：开始、执行中、结束
startAtstart_atDate执行开始时间
finishAtfinish_atDate执行结束时间
statusstatusString状态：成功、失败
resultresultString执行结果

OrmHookLog ORM钩子执行发件箱​

ORM 钩子执行发件箱，每次触发一行。事务提交后（afterCommit 回调）异步写入（ready）并立即尝试执行一次；失败由调度器异步扫描、抢占（CAS → processing）：成功 → success，失败 → 指数退避重试 → 死信（dead，可手动重放）。执行时按 hook_id 回读当前配置（配置被删/禁用则死信）；本表只存触发上下文快照，不复制动作配置，修改配置对未完成的重试立即生效。本表读写全部走 JdbcTemplate 直 SQL（不经 ORM save），从根上避免事件递归。继承 BaseEntity。

属性列名类型说明
hookIdhook_idString钩子配置 ID，非空，长度 32
eventIdevent_idString触发事件 ID（ORM 事件的 eventId），长度 36
entityNameentity_nameString实体名称，非空，长度 64
eventTypeevent_typeString事件类型：insert / update / delete，非空，长度 16
opTypeop_typeString操作类型：Insert / Update / Delete，长度 16
actionTypeaction_typeString动作类型，触发时刻的信息性快照：script / http；实际执行按当前配置，非空，长度 16
payloadJsonpayload_jsonString触发载荷 JSON：新值快照 values、会话信息 session、eventId 等
statusstatusString执行状态：ready / processing / success / dead，长度 16
retryCountretry_countint重试次数
nextRetryAtnext_retry_atDate下次重试时间
errorMsgerror_msgString错误信息，长度 512

EncodingLog 编码记录​

单据编码/流水号生成记录：按模板记录每次生成的实例与流水号。继承 BaseEntity。注意：该实体 catalog 为 email，落邮件库（历史归属），是本模块仅有的两个非 platform catalog 实体之一。

属性列名类型说明
encodingIdencoding_idString编码模板 ID
templatetemplateString模板
exampleexampleString实例（生成的编码值）
exampleDateexample_dateString时间
exampleSerialexample_serialString流水
enableStatusenable_statusint状态。有 enable_status 字段但未实现 EntityEnableAble 接口
descriptiondescriptionString备注

PlatformExceptionLog 平台错误日志​

平台异常/错误日志。继承 BaseEntity，catalog 为 platform-log（独立日志库）。错误码体系见错误码参考。

属性列名类型说明
happenedTimehappened_timeDate发生时间
exceptionClassexception_classString错误类对象，长度 255
exceptionStacktraceexception_stacktraceString错误堆栈
appIdapp_idString所属应用，长度 255
exceptionCodeexception_codeString错误编码，长度 255
tenantCodetenant_codeString租户编码。覆写基类字段以对齐表列长度 varchar(64)
