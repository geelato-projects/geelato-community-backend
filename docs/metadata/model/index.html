元数据模型

本页逐属性说明元数据体系的全部模型类。代码位置:geelato-core 的 cn.geelato.core.meta.model 包;注解在 geelato-lang 的 cn.geelato.lang.meta 包。

这些模型描述的是结构化数据本身,与存储介质无关:同样的属性契约,背后可以是 MySQL 的表、Excel 的工作表、MongoDB 的集合或任何其他结构化载体。

模型关系总览:

EntityMeta:实体元数据(聚合根)​

路径:cn.geelato.core.meta.model.entity.EntityMeta。

属性​

属性类型含义
entityNameString实体名。ORM 注解源为长类名;在线定义源为设计态维护的实体名
entityTitleString实体中文标题(来自 @Title 或设计态维护)
classTypeClass来源 Java 类。在线定义源实体为 null,这是区分两种来源的直接判据
entityTypeEntityType枚举 Table / View / Class,标记元数据的来源形态
catalogString,默认 "none"逻辑数据库分组,来自 @Entity(catalog),参与数据源路由
idFieldMeta主键字段元数据;setId 时同时把主键加入不可更新字段表
tableMetaTableMeta结构级定义(结构名/schema/连接 id/缓存类型等),见下文
tableAliasString结构别名(SQL 生成时使用)
fieldNamesString[]全部字段名的数组,按固定顺序排列(见 setFieldMetas)
fieldMetasCollection<FieldMeta>全部字段元数据
viewMetasCollection<ViewMeta>关联视图定义
tableForeignsCollection<TableForeign>外键关系;setTableForeigns 时同步构建 foreignTable → TableForeign 索引
tableChecksCollection<TableCheck>CHECK 约束
dictDataSourceMapMap<String, DictDataSource>字典数据源(fieldName → group/code),来自 @DictDataSrc
fieldMetaMapLinkedHashMap冗余索引:fieldName → FieldMeta,快速取列
simpleFieldMetaMapLinkedHashMap冗余索引:对外发布的精简字段元数据,过滤了库层信息
tableForeignsMapMap<String, TableForeign>冗余索引:foreignTable → TableForeign
ignoreUpdateFieldMapMap<String, Boolean>不可更新字段。构造时放入 create_at/createAt/creator,setId 时加入主键
encryptedColumnNamesSet<String>全部加密列名,懒计算一次,setFieldMetas 后重算
jsonFieldKeysSet<String>JSON 类型字段的键集合(同时含 fieldName 与 columnName),懒计算,用于 Dao 行转换时判定 JSON 解析
versionControlBoolean,默认 false版本控制(乐观锁)。当前暂缓启用:SQL 生成未消费该属性,以"未生效"为准
deleteModeDeleteMode,默认 AUTO实体级删除模式。AUTO=未显式指定,跟随全局默认;最终解析收敛在 DeleteCommands.resolve,优先级:调用级显式 > 实体级 > 全局默认
cacheTypeEntityCacheType(setter 私有)getter 实时读 tableMeta.cacheType,以设计态配置为准,不落自身字段

关键方法​

方法行为
setFieldMetas(Collection)构建三个冗余索引,并把字段按固定顺序重排:id → title → name → 业务字段(保持传入顺序)→ seq_no → description → del_status → create_at → creator → creator_name → update_at → updater → updater_name。同时清空加密列与 JSON 列的懒缓存
getColumnName(fieldName)字段名→列名;取不到元数据时抛异常(带 fieldName)
getFieldMeta(fieldName) / getFieldMetas(String[])按字段名取 FieldMeta(查 fieldMetaMap)
getFieldMetaByColumn(columnName)列名→FieldMeta,线性遍历;找不到时抛异常(带实体名/结构名/列名),打包部署的结构一致性校验即依赖此行为
getSimpleFieldMetas(String[]) / getAllSimpleFieldMetas()取对外发布的精简字段元数据
containsField(fieldName)判定字段是否存在;审计字段填充、逻辑删除字段填充都以它为准
isIgnoreUpdateField(field)判定是否不可更新字段
isBackEndCacheEnabled()查询结果缓存门控:cache_type ∈ {BackEnd, BackEndAndFrontEnd} 时为 true
getViewMeta(viewName)按视图名取关联视图

FieldMeta:字段元数据​

路径:cn.geelato.core.meta.model.field.FieldMeta。字段元数据是"Java 字段名"与"存储字段"之间的桥。

属性类型含义
columnMetaColumnMeta,final持有的列元数据,列级信息全部委托给它
fieldNameStringJava 字段名
fieldTypeClassJava 类型。ORM 注解源=字段反射类型;在线定义源=由列的 data_type 经 MysqlToJavaEnum.getJava 推导

派生方法:getColumnName() 即 columnMeta.getName()、getTitle()、isEquals()(列名与字段名是否一致)。

两个构造器对应两个来源:ORM 注解路径 (columnName, fieldName, title);在线定义装载路径 (ColumnMeta)。

ColumnMeta:列元数据​

路径:cn.geelato.core.meta.model.column.ColumnMeta。列元数据承载"一个存储字段"的完整定义,是 FieldMeta 的委托对象。

属性​

属性类型/默认值含义
appIdString应用 Id
titleString中文名
abstractColumnExpressionsString计算列表达式;非空即为抽象列
fieldNameStringJava 字段名
tableIdString所属结构 Id
tableSchemaString数据库名
tableNameString结构名
tableCatalogString结构目录(如 def)
nameString列名
commentString备注
ordinalPositionint=0列次序
defaultValueString=null默认值(auto_increment / null / current_timestamp / 自定义等)
typeString完整列类型(如 varchar(64))
keyboolean=false是否主键列
nullableboolean=true可空
dataTypeString数据类型(VARCHAR/INT…),SQL 生成时用于绑定 JDBC type
extraString附加信息,afterSet 时派生 UNIQUE/AUTO_INCREMENT/UNSIGNED
autoIncrementboolean=false自动递增
uniquedboolean=false唯一约束
charMaxLengthlong=64字符最大长度

特殊行为:afterSet() 依据 dataType 与 DataTypeRadiusEnum/MysqlDataTypeEnum 派生 type、extra、defaultValue、autoIncrement;另有 (Map<String,Object>) 构造器,从 MetaStore 装载的定义数据直接构造。

TableMeta:结构元数据​

路径:cn.geelato.core.meta.model.entity.TableMeta。承载"一个结构"的定义——结构名、schema、归属数据源、缓存类型等。

属性类型/默认值含义
appIdString应用 Id
titleString名称(中文)
connectIdString数据源连接标识,指向连接定义(ConnectMeta),数据源路由的最高优先级依据
dbTypeString数据库类型,参与 SQL 方言判定
tableSchemaString数据库 schema
tableNameString结构名
entityNameString实体名称
tableTypeString结构类型:entity / view / materialized
tableCommentString备注
enableStatusint=1启用状态
linkedint已链接
descriptionString补充描述
syncedBoolean=false同步状态
sourceTypeString来源类型:system / creation
packBusDataint=0数据打包策略
viewSqlString视图语句
acrossAppboolean=false跨应用
acrossWorkflowboolean=false跨工作流
cacheTypeString="none"缓存类型;EntityMeta.isBackEndCacheEnabled 的实际数据来源

versionControl 已在代码中注释禁用,待数据模型加列后多处同步启用。乐观锁当前未生效,SQL 生成不消费该属性。

方法:dbTableName()(tableName 为空时回退 entityName);(Map) 构造器(title 为空时回退 tableName→entityName)。

定义类的公共基类​

TableMeta、ColumnMeta、TableView、TableForeign、TableCheck、ConnectMeta 等定义类继承同一条基类链 IdEntity → BaseEntity → BaseSortableEntity,携带 String 主键 id、审计字段(createAt/creator/creatorName/buId/deptId/tenantCode/updateAt/updater/updaterName/deleteAt/delStatus)与排序号 seqNo。这是定义类自身的实现基座,服务于定义的装载、排序与维护,不是元数据模型对业务实体的要求;业务实体的公共字段约定见 ORM 注解说明。

TableForeign:外键关系​

承载两个结构之间的外键关系,ORM 查询 SQL 生成器依据它自动拼接 left join 并选取展示列;EntityMeta.tableForeignsMap 按 foreignTable 建索引。

属性含义
appId应用 Id
mainTableSchema主表 schema
mainTableId主表 Id
mainTable主表结构名
mainTableCol主表列
foreignTableSchema外表 schema
foreignTableId外表 Id
foreignTable外表结构名
foreignTableCol外表列
description描述
enableStatus启用状态
deleteAction删除动作(默认 FOREIGN_ACTION_VALUE)
updateAction更新动作(默认 FOREIGN_ACTION_VALUE)

TableCheck:CHECK 约束​

承载结构的 CHECK 约束定义。属性:appId、title、code、type、checkClause(约束表达式)、connectId、tableSchema、tableId、tableName、columnId、columnName、description、enableStatus、synced。

视图元数据:TableView / ViewMeta / ViewColumn​

TableView 承载视图的定义:

属性含义
appId应用 Id
connectId连接 id(物化视图有自己的连接;虚拟视图为空时继承主体实体)
entityName主体实体名
title名称
viewName视图名
viewType视图类型
viewConstruct视图构造语句
viewColumn视图列(JSON 字符串)
description描述
linked已链接
enableStatus启用状态

ViewMeta(非实体)是注册进 EntityMeta 的运行时形态,持有 viewMeta(TableView)、viewName、viewType、viewConstruct、viewColumn、subjectEntity(主体实体名)。ViewColumn(非实体)承载视图列定义(table_name/column_name/field_name/title/select_type/长度与精度等),静态方法 fromColumnMeta(ColumnMeta) 从列元数据转换。

ConnectMeta:连接定义​

承载数据源连接的定义。$gl.sql kit 的跨库定位(MetaTableLocationResolver)即凭"结构→EntityMeta→connectId→这行连接定义"完成物理库定位。

属性含义
appId应用 Id
dbConnectName连接名
dbName数据库名
dbSchemaschema
dbType数据库类型
dbUserName用户名
dbPassword连接密码
dbPort端口
dbHostnameIp主机地址
enableStatus启用状态

对外发布模型​

这些轻量模型不进 MetaManager 注册表,是元数据对外的"出口形态"。

SimpleFieldMeta​

EntityMeta.getSimpleFieldMetas / getAllSimpleFieldMetas 的产出,过滤掉结构名、schema 等库层信息,是低码前端渲染表单/表格的契约:

属性类型来源(ColumnMeta)
nameStringfieldName
typeStringfieldType 的 simpleName
titleStringtitle
commentStringcomment
nullablebooleannullable
charMaxLengthlongcharMaxLength
precisionintnumericPrecision
scaleintnumericScale
selectTypeStringselectType
typeExtraStringtypeExtra
extraValueStringextraValue
extraMapStringextraMap
defaultValueStringdefaultValue

EntityLiteMeta​

精简实体列表项(经 MetaManager.getAllEntityLiteMetas 对外提供):entityName、entityTitle、entityType(String)。

DictDataSource​

字典数据源声明(来自 @DictDataSrc):group(字典组)、code(字典码,默认 "code")。审计日志的字典翻译(DictDisplayResolver)凭它把字段值翻译为字典标签。

注解 → 元数据属性映射​

这些注解要与 ORM 结合来看:它们既是 ORM 的实体映射声明,也是元数据的声明形态,元数据与 ORM 共用同一套注解,声明即映射。注解定义在 geelato-lang 的 cn.geelato.lang.meta 包,由 MetaReflex#getColumnFieldMetas 解析为 FieldMeta/ColumnMeta。注解的写法与示例见 ORM 注解说明,本节只列属性契约。

@Entity(标注在类上)​

属性默认值映射到
name""(空取类名)entityName;结构名解析顺序 table→name→simpleName
table""结构名
catalog""EntityMeta.catalog,参与数据源路由
schema""schema
connectId""显式数据源 key,优先级高于 catalog 映射
deleteModeDeleteMode.AUTOEntityMeta.deleteMode

@Col(标注在字段/getter 上)​

属性默认值映射到 ColumnMeta
name必填列名
uniquefalse唯一约束
nullabletrue可空
dataType""(空则由 Java 类型推导)数据类型
charMaxlength0(0 时按 dataType 取默认:Text 类 65535,其余 64)字符长度
numericPrecision20整数位
numericScale0小数位
datetimePrecision0日期精度
isRefColumnfalse是否外表字段
refLocalCol""本表引用字段
refColName""外表字段
refTables""外表结构名

其余注解​

注解标注位置属性作用
@TitleTYPE/METHOD/FIELDtitle(必填)、description实体/字段中文名,进入 entityTitle 与 ColumnMeta.title
@IdMETHOD/FIELD无属性标记主键;getter 上标注时从方法名推字段名
@TransientMETHOD/FIELD无属性解析时跳过,并记录防止子类重复解析
@IgnoreFIELDtype(): IgnoreType[],默认 {}按 PAGE_QUERY/QUERY/GET/SAVE/UPDATE/DELETE 维度排除
@ForeignKeyMETHOD/FIELDfTable(必填,外表实体 Class)、fCol(空取 fTable 的 @Id 列)生成 TableForeign
@DictDataSrcMETHOD/FIELDgroup(必填)、code(默认 "code")进入 dictDataSourceMap

DeleteMode 枚举​

值含义
AUTO仅作注解默认值,表示跟随全局默认(GEELATO_DELETE_MODE 环境变量,默认 logic)
LOGIC逻辑删除;实体须含 delStatus 字段,否则硬失败
PHYSICAL物理删除

解析细节:先扫字段再扫 get/is 方法;@Col 缺失时按字段名生成(驼峰转下划线);布尔默认值取 bean 实例字段值转 "1"/"0";dataType 为空时经 TypeConverter.toSqlTypeString(fieldType) 推导;最后统一走 ColumnMeta.afterSet()。

物理结构反射模型(schema 包)​

cn.geelato.core.meta.schema 包的模型用于从物理存储反向采集结构定义,支撑"物理结构 ↔ 元数据"的对照与一致性检查。当前适配 MySQL 的 information_schema 与 SHOW INDEX;按框架抽象,物理载体不限——其他介质的反射采集属扩展方向。

类数据来源说明
SchemaTableinformation_schema.tables21 个字段全列直映
SchemaColumnINFORMATION_SCHEMA.COLUMNS含 unique;convertIntoMeta(ColumnMeta) 转成 ColumnMeta 并触发 afterSet
SchemaIndexSHOW INDEX索引信息载体;不进 MetaManager,仅反射对照使用
SchemaForeign约束 + KEY_COLUMN_USAGEconvertTableForeign(TableForeign) 转换
SchemaCheckTABLE_CONSTRAINTS + CHECK_CONSTRAINTSCHECK 约束反射

框架没有名为 IndexMeta/RelationMeta 的类:索引由 SchemaIndex 承载,"关系"由 TableForeign 承载。
