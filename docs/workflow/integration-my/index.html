个人流程集成

本页逐一说明以当前登录用户为维度的流程查询与操作接口：我的待办、已办、待阅、已阅、我发起的流程、审批常用语与传阅。数据范围自动限定为当前用户，无需（也无法）传用户参数。

通用约定​

  • 接口统一 /api 前缀，响应体与分页结构见流程定义集成 · 通用约定。
  • 分页查询均支持统一关键字（keyword）、服务端排序（sortBy 服务端白名单校验 / sortOrder 仅 asc / desc）与分页（page 默认 1、pageSize 默认 10）。
  • 时间参数格式统一 yyyy-MM-dd HH:mm:ss，区间含边界。

公共出参结构​

MyTask​

待办/已办条目：

字段说明
id任务 id（办理接口的 taskId 取此值）
procInstId流程实例 id
procInstName实例名称（【定义名】业务名）
procDefName流程定义名称
taskDefId任务定义 id（节点 id）
taskName任务名称
formRecordId业务记录 id（businessKey）
description任务描述
assigneeId / assigneeName办理人 id / 姓名（即当前用户）
ownerId / ownerName发起人 id / 姓名
createTime实例发起时间
arriveTime任务到达当前节点时间
finishTime任务完成时间（仅已办）

ToReadVo​

待阅/已阅条目：

字段说明
id待阅记录 id（办结待阅接口的 id 取此值）
procInstId / procInstName流程实例 id / 名称
procDefName流程定义名称
taskId关联流程任务 id
formRecordId业务记录 id
recipientId / recipientName接收人 id / 姓名（即当前用户）
senderId / senderName传阅人 id / 姓名
comment传阅意见
receiveTime接收时间（yyyy-MM-dd HH:mm:ss）
readAt阅读时间（仅已阅）

我的待办​

GET /api/my/getMyPendingTask​

查询当前用户全部待办任务（不分页，全量列表）。

入参（query）：

参数类型必填说明
appIdstring否按流程定义所属应用过滤，为空不过滤

出参（data[]）：MyTask 列表。

GET /api/my/pageQueryMyPendingTask​

分页查询当前用户待办任务。

入参（query）：

参数类型必填说明
keywordstring否统一关键字（实例名称/任务名称等模糊匹配）
appIdstring否按所属应用过滤
procDefKeysstring否流程类型（定义 key），多个逗号分隔
arriveTimeFrom / arriveTimeTostring否到达时间区间（含边界）
stayLevelstring否停留时长档位：lt8h 8 小时内 / 8to24h 8 至 24 小时 / gt24h 超 24 小时
startUserIdstring否按发起人过滤
sortBy / sortOrderstring否排序字段（如 arriveTime）/ 方向
page / pageSizeint否分页，默认 1 / 10

出参（data）：PageResult，data[] 为 MyTask 列表。total 由同口径统计得出，翻页结果连续。

响应示例：

{
  "code": 200, "status": "success", "msg": "success",
  "data": {
    "page": 1, "pageSize": 10, "total": 1,
    "data": [
      {
        "id": "6001", "procInstId": "5001",
        "procInstName": "【请假申请】张三的请假申请",
        "procDefName": "请假申请", "taskDefId": "audit_1", "taskName": "主管审批",
        "formRecordId": "LV202611150001",
        "assigneeId": "u_2001", "assigneeName": "李四",
        "ownerId": "u_1001", "ownerName": "张三",
        "createTime": "2026-11-15 10:00:00",
        "arriveTime": "2026-11-15 10:05:00", "finishTime": null
      }
    ]
  }
}

我的已办​

GET /api/my/getMyCompleteTask​

查询当前用户全部已办任务（不分页）。

入参（query）：appId（string，可选，按所属应用过滤）。

出参（data[]）：MyTask 列表（含 finishTime）。

GET /api/my/pageQueryMyCompleteTask​

分页查询当前用户已办任务。

入参（query）：

参数类型必填说明
keywordstring否统一关键字
appIdstring否按所属应用过滤
procDefKeysstring否流程类型，多个逗号分隔
finishTimeFrom / finishTimeTostring否完成时间区间（含边界）
durationLevelstring否办理耗时档位：lt1h 1 小时内 / 1to8h 1 至 8 小时 / 8to24h 8 至 24 小时 / gt24h 超 24 小时
startUserIdstring否按发起人过滤
sortBy / sortOrderstring否排序字段（如 finishTime）/ 方向
page / pageSizeint否分页，默认 1 / 10

出参（data）：PageResult，data[] 为 MyTask 列表。

我的待阅​

GET /api/my/getMyToRead​

查询当前用户全部待阅（不分页）。

入参（query）：appId（string，可选）。

出参（data[]）：ToReadVo 列表。

GET /api/my/pageQueryMyToRead​

分页查询当前用户待阅。

入参（query）：

参数类型必填说明
keywordstring否统一关键字
appIdstring否按所属应用过滤
procDefKeysstring否流程类型，多个逗号分隔
receiveTimeFrom / receiveTimeTostring否接收时间区间（含边界）
senderIdstring否按传阅人过滤
stayLevelstring否待阅停留档位：lt8h / 8to24h / gt24h
sortBy / sortOrderstring否排序字段 / 方向
page / pageSizeint否分页，默认 1 / 10

出参（data）：PageResult，data[] 为 ToReadVo 列表。

我的已阅​

GET /api/my/getMyCompleteRead​

查询当前用户全部已阅（不分页）。

入参（query）：appId（string，可选）。

出参（data[]）：ToReadVo 列表（含 readAt）。

GET /api/my/pageQueryMyCompleteRead​

分页查询当前用户已阅。

入参（query）：与我的待阅分页查询一致，另增加：

参数类型必填说明
readAtFrom / readAtTostring否已阅时间区间（含边界，仅已阅列表生效）

出参（data）：PageResult，data[] 为 ToReadVo 列表。

我发起的​

GET /api/my/getMyStart​

分页查询当前用户发起的流程实例（发起人固定为当前用户）。

入参（query）：与实例分页查询一致（status / procDefKeys / 时间区间 / 排序 / 分页），startUserId 参数无需传入。

出参（data）：PageResult，data[] 为 ProcInstListVo 列表。

审批常用语​

当前用户个人的审批常用语，用于意见框快捷输入；数据归属当前用户，仅本人可见可改。

GET /api/my/getOpinionPhraseList​

查询当前用户常用语列表。无入参。

出参（data[]）：

字段说明
id常用语 id
text常用语文本
enabled是否启用：0 停用（不展示于意见框下方）/ 1 启用
sortOrder排序序号，升序展示（越小越靠前）

POST /api/my/saveOpinionPhrase​

新增常用语（id 为空时新增，否则更新；归属当前用户）。

入参（JSON body）：

字段类型必填说明
textstring是常用语文本
enabledint否0 停用 / 1 启用
sortOrderint否排序序号

出参（data）：保存后的常用语（含 id）。

PUT /api/my/updateOpinionPhrase​

更新常用语（文本/启停/排序的部分更新；id 必填且须为本人所有）。

入参（JSON body）：在新增基础上，id（string）必填。

出参（data）：更新后的常用语。

DELETE /api/my/deleteOpinionPhrase​

删除常用语（逻辑删除，须为本人所有）。

入参（query）：id（string，必填）。

出参（data）："success"。

传阅​

发送待阅​

POST|GET /api/toRead/sendToRead​

把流程实例发给指定人员查阅，为每个接收人生成一条待阅。

入参（query 或 form）：

参数类型必填说明
procInstIdstring是流程实例 id
taskIdstring否关联任务 id
recipientIdsstring是接收人用户 id，多个逗号分隔
commentstring否传阅意见

出参（data）：处理结果描述字符串。

业务规则：仅实例相关人（发起人/处理人/已处理人）可发送传阅；传阅动作写入操作记录（CIRCULATE）。

完成待阅​

POST|GET /api/toRead/completeRead​

办结本人一条待阅（标记已阅）。

入参（query 或 form）：

参数类型必填说明
idstring是待阅记录 id（待阅列表 ToReadVo.id）

出参（data）：处理结果描述字符串。

批量完成待阅​

POST|GET /api/toRead/batchCompleteRead​

批量办结本人待阅。

入参（query 或 form）：

参数类型必填说明
idsstring是待阅记录 id，多个逗号分隔

出参（data）：成功办结条数。
