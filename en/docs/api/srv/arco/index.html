Arco Components (arco)

1 controller with 1 endpoint in total. All endpoints in this domain are design-time APIs.

ArcoController ⚙ — /arco​

Arco form component support: returns select option data for a registered enum code.

getSelectOptionData Get select option data​

ItemContent
URLGET /api/arco/sod/{code}
Paramscode: path, string, enum code (registered in ArcoEnum, case-insensitive).
ReturnsApiResult<List<SelectOptionData>>: data is the select option list (label/value, etc.); an empty list is returned when the code does not exist or the enum is invalid.
