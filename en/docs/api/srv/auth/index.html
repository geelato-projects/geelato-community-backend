Authentication (auth)

2 controllers with 18 endpoints in total. Controllers marked with ⚙ are design-time APIs.

JWTAuthController — /user​

Core of login and current-user self-service operations: account/anonymous login, identity and tenant switching, delegate-on-behalf sessions, current user info and menus, avatar and profile maintenance, password reset and recovery, account verification and binding.

login Log in​

ItemContent
URLPOST /api/user/login
Paramsusername: body, string, required, login name (max 64).
password: body, string, required, login password (max 128).
tenant: body, string, optional, tenant code.
suffix: body, string, optional, login-name suffix (e.g. @tenant; when non-empty it takes precedence over tenant for tenant resolution).
org: body, string, optional, reserved field (not used by the current login logic).
ReturnsApiResult<LoginResult>: on success returns a full identity isomorphic to Current user info (basic user info, org/company info, org list orgs, tenant list tenants, role strings roleCodes/roleIds) plus a token; the JWT payload fields are id, loginName, passWord, orgId, tenantCode. When the login name exists under multiple tenants, the call fails with a multi-tenant exception code and data.tenants carries the candidate tenant list for you to choose from.

loginAnonymous Anonymous login​

ItemContent
URLPOST /api/user/login/anonymous
Paramsusername: body, string, required, anonymous account login name.
password: body, string, required, must equal the platform-configured anonymous fixed password.
Other fields are the same as login.
ReturnsApiResult<LoginResult>: same as login; the JWT payload additionally carries an anonymous field. The platform anonymous-login option must be enabled, otherwise the call fails.
The anonymous channel is decided by the global context: the environment variable GEELATO_ANONYMOUS_ENABLED (true/false) takes precedence when set; otherwise it follows the security level (on when level < 10, off when level ≥ 10). See Global Context.

switchIdentity Switch identity​

ItemContent
URLGET /api/user/switchIdentity
Paramsorg: query, string, optional, target org ID.
tenant: query, string, optional, target tenant code.
ReturnsApiResult<LoginResult>: re-issues the JWT with the new orgId/tenantCode and returns the full login result (same structure as Current user info); if the given org or tenant is not among your options, it falls back to the user's default value. Delegate mode ends with the old credential when the token is re-issued.

delegators Delegatable principals​

ItemContent
URLGET /api/user/delegators
ParamsNone
ReturnsApiResult<List<UserDelegateMap>>: list of principals you (as the delegate) may act on behalf of (records with scope=mentor_assist, enabled and valid, deduplicated by principal ID), for the top-right delegate switcher. Fails when you are not logged in.

delegateAs Act as delegate​

ItemContent
URLGET /api/user/delegateAs
ParamstargetUserId: query, string, target principal user ID.
ReturnsApiResult<LoginResult>: does not re-issue any token; it only writes a server-side "credential → delegation target" session mapping and returns the target principal's basic user info (whitelist DTO, credential fields excluded). Checks: a valid delegation relationship must exist; nested delegation and delegating to yourself are forbidden.

exitDelegate Exit delegate mode​

ItemContent
URLGET /api/user/exitDelegate
ParamsNone
ReturnsApiResult<NullResult>: data is empty; removes the delegation session for the current credential and clears the delegate-mode context cache, restoring your own identity.

getUserInfo Current user info​

ItemContent
URLGET|POST /api/user/info
ParamsNone
ReturnsApiResult<LoginResult>: full current-user info, including token, org list orgs, tenant list tenants, role info roles/roleCodes/roleIds, and delegateUserId/delegateUserName when in delegate mode.

logout Log out​

ItemContent
URLPOST /api/user/logout
ParamsNone
ReturnsApiResult<NullResult>: data is empty.

uploadAvatar Upload avatar​

ItemContent
URLPOST|GET /api/user/avatar/{userId}
ParamsuserId: path, string, target user ID.
file: form, multipart file, avatar file (parameter name file).
ReturnsApiResult<NullResult>: data is empty.

updateUserInfo Update profile​

ItemContent
URLPOST|GET /api/user/update/{userId}
ParamsuserId: path, string, target user ID.
name: body, string, optional, name (max 64).
enName: body, string, optional, English name (max 64).
mobilePrefix: body, string, optional, mobile prefix (max 16).
mobilePhone: body, string, optional, mobile number (max 16).
telephone: body, string, optional, telephone (max 64).
email: body, string, optional, email (max 128).
nationCode, provinceCode, cityCode: body, string, optional, nation/province/city codes (max 32).
address: body, string, optional, address (max 255).
description: body, string, optional, description (max 255).
ReturnsApiResult<NullResult>: data is empty.

getCurrentUserMenu Current user menus​

ItemContent
URLPOST|GET /api/user/menu
Paramsflag: body, string, optional, filter flag passed through to the menu query.
appId: body, string, optional, application ID.
tenantCode: body, string, optional, tenant code; when non-empty it must match your current tenant, otherwise validation fails.
ReturnsApiResult<List<Map<String,Object>>>: menu nodes authorized for the current user (queried by app/tenant). Returns an empty list when appId or the tenant code is missing.

resetPassword Reset current user password​

ItemContent
URLPOST|GET /api/user/resetPassword
ParamspasswordLength: query, int, optional, length of the new password; default 8, max 32.
ReturnsApiResult<String>: data is the newly generated random plaintext password.

forgetValid Locate account for recovery​

ItemContent
URLPOST /api/user/forgetValid
ParamsvalidType: body, string, required, verification type (1 mobile, 2 email, 3 password).
validBox: body, string, required, mobile number or email.
prefix: body, string, required when validType is 1, mobile prefix.
ReturnsApiResult<User>: data contains only the id of the matched user (for the subsequent recovery steps); throws a business exception when no unique user matches.

forgetPassword Reset forgotten password​

ItemContent
URLPOST /api/user/forget
Paramsaction: body, string, required, business action identifier (used for auth-code validation).
validType: body, string, required, verification type (1 mobile, 2 email).
validBox: body, string, required, mobile number or email.
authCode: body, string, required, auth code.
userId: body, string, required, user ID.
password: body, string, required, new password.
prefix: body, string, optional, mobile prefix.
ReturnsApiResult<NullResult>: data is empty; resets the user's password after the auth code is validated.

validateUser Verify user​

ItemContent
URLPOST /api/user/validate
ParamsvalidType: body, string, required, verification type (1 mobile, 2 email, 3 password).
userId: body, string, required, user ID.
authCode: body, string, required, auth code; used as the login password when validType is 3.
prefix: body, string, optional, mobile prefix.
ReturnsApiResult<NullResult>: data is empty; validates the auth code or password according to the verification type, and throws a business exception on failure.

bindAccount Bind account​

ItemContent
URLPOST /api/user/bindAccount
ParamsvalidType: body, string, required, binding type (1 mobile, 2 email, 3 password).
userId: body, string, required, user ID.
authCode: body, string, required, auth code.
validBox: body, string, required, mobile number/email/new password.
prefix: body, string, optional, mobile prefix.
ReturnsApiResult<NullResult>: data is empty; when validType is 3 the validBox is encrypted and saved as the new login password; when it is 1/2 the mobile number or email is bound after the auth code is validated.

OAuth2Controller — /oauth2​

OAuth2 integration login: exchanges an authorization code for tokens at the OAuth server, fetches user info to complete the login on this platform, and refreshes access tokens.

login OAuth2 login​

ItemContent
URLPOST /api/oauth2/login
Paramscode: query, string, OAuth2 authorization code.
ReturnsApiResult<LoginResult>: exchanges the code for tokens using the platform-configured OAuth server URL and client credentials, fetches user info, stores the access/refresh token mapping, and assembles the full login result from the platform's stored user record matched by user ID (token is the OAuth access token). Fails when token exchange or user-info fetching fails, when the SSO data lacks a user ID, or when the matching platform account does not exist.

refreshToken Refresh access token​

ItemContent
URLPOST /api/oauth2/refreshToken
ParamsoldToken: query, string, old access token.
ReturnsApiResult<HashMap<String,String>>: data contains access_token and refresh_token; looks up the refresh token by the old token, exchanges it at the OAuth server for new tokens, and updates the token mapping on success. Fails when no refresh token is found or the exchange fails.
