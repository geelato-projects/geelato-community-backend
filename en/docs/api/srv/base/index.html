Platform Basics (base)

15 controllers with 46 endpoints in total. Endpoints marked with ⚙ are design-time APIs.

AuxiliarySuiteHealthController ⚙ — /system/monitor/auxiliary-suites​

Health status query and manual refresh for auxiliary suites, admin-only.

health Health status query​

ItemContent
URLGET /api/system/monitor/auxiliary-suites/health
ParamsNone
ReturnsApiResult<AuxiliarySuiteHealthSummary>: auxiliary suite health summary (checked time, poll interval in seconds, suite count with healthy/abnormal/unknown counts, hasFailure flag, last error, per-suite snapshot list suites); fails for non-admin users.

refresh Immediate health refresh​

ItemContent
URLGET、POST /api/system/monitor/auxiliary-suites/refresh
ParamsNone
ReturnsApiResult<AuxiliarySuiteHealthSummary>: latest summary after running a health check immediately; fails for non-admin users.

CacheController — /cache​

Key listing, removal, and clearing for J2Cache, plus its runtime configuration.

remove Remove cache keys​

ItemContent
URLGET、POST /api/cache/remove/{keys}
Paramskeys: path, string, required, comma-separated cache keys, removed one by one (blank entries skipped); fails when empty.
ReturnsApiResult<NullResult>: data is empty.

config Cache configuration view​

ItemContent
URLGET /api/cache/config
ParamsNone
ReturnsApiResult<Map<String,Object>>: l1/l2 (enabled flag and provider; l2.config includes redis mode, hosts, namespace, database, with the password masked), config (open_spring_cache, clean_on_start, broadcast, serialization, default_cache_expire), capabilities (channel_present, clear_region_supported, evict_supported).

listL1 L1 cache list​

ItemContent
URLGET /api/cache/list/l1
Paramskeyword: query, string, optional, fuzzy filter on cache keys (case-insensitive).
ReturnsApiResult<List<Map<String,Object>>>: level-1 (L1) cache entries, each with key, type (L1), region, size (UTF-8 bytes), createTime (always null), expireTime (null).

listL2 L2 cache list​

ItemContent
URLGET /api/cache/list/l2
Paramskeyword: query, string, optional, fuzzy filter on cache keys (case-insensitive).
ReturnsApiResult<List<Map<String,Object>>>: level-2 (L2) cache entries with the same fields as listL1 but type of L2; expireTime is derived from the Redis TTL (only available in redis single mode, otherwise null).

get Get cache value​

ItemContent
URLGET /api/cache/get/{key}
Paramskey: path, string, required, cache key; fails when empty.
ReturnsApiResult<Object>: data is the cached value (fetched reflectively via CacheUtil get/getValue, null when absent).

clearAll Clear caches​

ItemContent
URLGET、POST /api/cache/clear
ParamsNone
ReturnsApiResult<NullResult>: clears the default region (channel.clear), falling back to per-key removal when the channel is unavailable. data is empty.

ConfigController — /config​

Platform system configuration query (grouped by platform/tenant/app) and refresh of a given config key.

list Platform configuration query​

ItemContent
URLGET /api/config
ParamstenantCode: query, string, optional, emits the tenant group when tenant-level configs match.
appId: query, string, optional, emits the app group when app-level configs match.
ReturnsApiResult<Map<String,Object>>: grouped key-value pairs: platform (global), tenant (given tenant), app (given app), merged from the webapp and all config purposes.

refresh Refresh config key​

ItemContent
URLGET /api/config/refresh/{configKey}
ParamsconfigKey: path, string, required, config key.
ReturnsApiResult<NullResult>: refreshes the given config via EnvManager, data is empty; returns a failure message on exception.

DictionaryController — /system/dictionary​

Query enabled dictionary items by dictionary code.

getByCode Dictionary items by code​

ItemContent
URLGET /api/system/dictionary/{code}
Paramscode: path, string, dictionary code; returns an empty list when blank.
ReturnsApiResult<List<DictItem>>: enabled, non-deleted dictionary items ordered by seqNo ascending; empty list when the dictionary does not exist.

DownloadController — /resources​

Attachment file download and site configuration file reading.

downloadFile Download attachment​

ItemContent
URLGET /api/resources/file
Paramsid: query, string, attachment ID.
isPdf: query, boolean, convert to PDF before download (requires the aspose dependency on the host).
isPreview: query, boolean, preview mode.
isThumbnail: query, boolean, download the thumbnail.
name, path: query, string, declared in the method signature but not used by the current handler logic.
ReturnsWrites the response stream directly (no JSON body): fetches the attachment by ID (from OSS or the local path) and streams it under the original file name; with isPdf=true it converts to PDF and streams under a PDF file name; responses carry Cache-Control, ETag, and Last-Modified headers.

downloadJson Read site config​

ItemContent
URLGET /api/resources/json
ParamsfileName: query, string, required, config file name; the .config suffix is appended automatically when missing.
ReturnsApiResult<String>: data is the full site configuration file content (UTF-8); fails when the file does not exist.

IDGenerateController — /id​

Generate a globally unique ID.

generate Generate unique ID​

ItemContent
URLGET /api/id/generate
ParamsNone
ReturnsApiResult<Long>: data is a unique ID generated by UIDGenerator.generate() (long).

OrganizationController — /org​

Query an organization record by organization ID.

getOrgById Organization by ID​

ItemContent
URLGET /api/org/{orgId}
ParamsorgId: path, string, organization ID.
ReturnsNot wrapped in ApiResult; returns the JSON object Map<String,Object> directly: {success: true, data: <organization record>} (a full platform_org row) on success, {success: false, message: <reason>} on failure.

PageCheckController — /page/check​

Page check-out/check-in and page takeover request (check request) workflow.

checkPage Page check-out/check-in​

ItemContent
URLPOST /api/page/check
ParamspageId: body, string, required, page ID.
action: body, string, required, checkout / checkin.
force: body, boolean, optional, force check-in when the page is held by another user (checkin only; requires app admin permission).
ReturnsApiResult<Map<String,Object>>: data contains checkStatus, checkUserId, checkUserName, checkAt; each check-out/check-in branch returns its own success or failure message.

getCheckedOutPageList Checked-out page list​

ItemContent
URLGET /api/page/check/list
ParamsappId: query, string, required, app ID.
ReturnsApiResult<List<Map<String,Object>>>: checked-out, non-deleted pages of the app, each with pageId, extendId, title, checkUserId, checkUserName, checkAt, lastUpdateTime.

syncPageStatus Sync page status​

ItemContent
URLGET /api/page/check/sync
ParamspageId: query, string, required, page ID.
ReturnsApiResult<Map<String,Object>>: page check status: checkStatus, checkUserId, checkUserName, checkAt, version, lastUpdateTime.

requestPageCheckOut Request page takeover​

ItemContent
URLPOST /api/page/check/request
ParamspageId: body, string, required, page ID.
targetUser: body, string, required, target user ID (takeover recipient).
ReturnsApiResult<Map<String,Object>>: data contains requestId; fails when a pending request already exists for the page.

getCheckRequestList Check request list​

ItemContent
URLGET /api/page/check/request/list
ParamsuserId: query, string, required, target user ID.
status: query, string, optional, filter by request status.
ReturnsApiResult<List<AppPageCheckReq>>: check requests addressed to this user.

processCheckRequest Process check request​

ItemContent
URLPOST /api/page/check/request/process
ParamsrequestId: body, string, required, request ID.
action: body, string, required, approve / reject.
comment: body, string, optional, processing comment.
ReturnsApiResult<Map<String,Object>>: data contains pageId and checkStatus; with approve the page is checked in (the processor is recorded as the check-in user); only pending requests can be processed.

cancelCheckRequest Cancel check request​

ItemContent
URLPOST /api/page/check/request/cancel
ParamsrequestId: body, string, required, request ID.
ReturnsApiResult<String>: only the requester can cancel a pending request; the status becomes rejected with processing info recorded, data is a success message string.

PageController — /page_v1​

Page configuration API V1 (original implementation, kept as the fallback reference for V2): runtime/design-time page definition, language packs, save, and update notifications.

getPageAndCustom Page definition and custom config​

ItemContent
URLGET /api/page_v1/getPageAndCustom/{idType}/{id}、GET /api/page_v1/getPageAndCustom/{idType}/{id}/*
ParamsidType: path, string, pageId or extendId.
id: path, string, the corresponding ID value.
ReturnsApiResult<HashMap<String,Object>>: runtime page data: id, type, appId, code, releaseContent (JSON string), sourceContent (empty string, no source), pageLang (language pack for the current locale), pageCustom (the current user's custom config for this page), pagePerms (the current user's operation permissions on this page).

getPageById Page config by ID​

ItemContent
URLGET /api/page_v1/getPageById/{pageId}
ParamspageId: path, string, page ID.
ReturnsApiResult<HashMap<String,Object>>: full design-time config: same fields as getPageAndCustom, but sourceContent is the page source while pageCustom and pagePerms are empty strings.

getPageByExtendId Page config by extend ID​

ItemContent
URLGET /api/page_v1/getPageByExtendId/{extendId}
ParamsextendId: path, string, page tree node extend ID.
ReturnsSame as getPageById, queried by extend ID.

getPageLang Page language pack​

ItemContent
URLGET /api/page_v1/getPageLang/{idType}/{id}、GET /api/page_v1/getPageLang/{idType}/{id}/*
ParamsidType: path, string, pageId or extendId.
id: path, string, the corresponding ID value.
ReturnsApiResult<HashMap<String,Object>>: pageLang (language pack content for the current locale), locale (current locale); used to switch languages after the page has loaded.

notifyUpdate Page update notification​

ItemContent
URLGET、POST /api/page_v1/notifyUpdate/{pageId}/{extendId}
ParamspageId: path, string, page ID.
extendId: path, string, page extend ID.
ReturnsApiResult<String>: publishes the page upgrade event so all clients refresh the page config, data is a success message string.

savePage Save page config​

ItemContent
URLPOST /api/page_v1/savePage
ParamsappPage: body, AppPage entity (no @RequestBody annotation; Spring binds it from query/form parameters), common fields such as id, appId, code, title, extendId, description, sourceContent; a non-empty id means update with the version incremented, an empty id means create (version 1).
ReturnsApiResult<AppPage>: the saved page (version updated); also writes a page log, evicts page caches, and publishes the page update event.

PageV2Controller — /page​

Page configuration API V2 (performance-optimized, paths identical to V1): runtime pageLang/pageCustom/pagePerms queries run in parallel, and releaseContent is returned as a native JSON object at runtime.

getPageAndCustom Page definition and custom config​

ItemContent
URLGET /api/page/getPageAndCustom/{idType}/{id}、GET /api/page/getPageAndCustom/{idType}/{id}/*
ParamsidType: path, string, pageId or extendId.
id: path, string, the corresponding ID value.
ReturnsApiResult<HashMap<String,Object>>: same fields as V1 getPageAndCustom, but releaseContent is parsed and returned as a native JSON object (falling back to the original string on parse failure); the three secondary queries run in parallel.

getPageById Page config by ID​

ItemContent
URLGET /api/page/getPageById/{pageId}
ParamspageId: path, string, page ID.
ReturnsApiResult<HashMap<String,Object>>: full design-time config (serial logic identical to V1): sourceContent is the page source, pageCustom and pagePerms are empty strings, releaseContent stays a JSON string.

getPageByExtendId Page config by extend ID​

ItemContent
URLGET /api/page/getPageByExtendId/{extendId}
ParamsextendId: path, string, page tree node extend ID.
ReturnsSame as getPageById, queried by extend ID.

getPageLang Page language pack​

ItemContent
URLGET /api/page/getPageLang/{idType}/{id}、GET /api/page/getPageLang/{idType}/{id}/*
ParamsidType: path, string, pageId or extendId.
id: path, string, the corresponding ID value.
ReturnsApiResult<HashMap<String,Object>>: pageLang (language pack content for the current locale), locale (current locale).

notifyUpdate Page update notification​

ItemContent
URLGET、POST /api/page/notifyUpdate/{pageId}/{extendId}
ParamspageId: path, string, page ID.
extendId: path, string, page extend ID.
ReturnsApiResult<String>: publishes the page upgrade event, data is a success message string.

savePage Save page config​

ItemContent
URLPOST /api/page/savePage
ParamsappPage: body, AppPage entity (no @RequestBody annotation; Spring binds it from query/form parameters), common fields such as id, appId, code, title, extendId, description, sourceContent; a non-empty id means update with the version incremented, an empty id means create (version 1).
ReturnsApiResult<AppPage>: the saved page (version updated); also writes a page log, evicts page caches, and publishes the page update event.

ScheduledTaskMonitorController ⚙ — /system/monitor/scheduled-tasks​

Platform scheduled-task monitoring summary query and manual scan, admin-only.

list Task monitoring summary​

ItemContent
URLGET /api/system/monitor/scheduled-tasks
ParamsNone
ReturnsApiResult<ScheduledTaskMonitorSummary>: scheduled-task monitoring summary (scanned time, task count with active/inactive/running/success/failed/neverRun counts, last error, task snapshot list tasks); fails for non-admin users.

refresh Immediate task scan​

ItemContent
URLGET、POST /api/system/monitor/scheduled-tasks/refresh
ParamsNone
ReturnsApiResult<ScheduledTaskMonitorSummary>: latest summary after an immediate scan; fails for non-admin users.

SqlKeyController — /sk​

Execute SQL by named SQL key, with optional datasource switching.

exec Execute named SQL​

ItemContent
URLPOST /api/sk/{key}
Paramskey: path, string, required, named SQL key.
connectId: query, string, optional, datasource connection ID; when provided the SQL runs against that datasource.
paramMap: body, Map<String,Object>, SQL parameters (values for the named SQL template).
ReturnsApiResult<Object>: determined by the SQL's configured response type: map/object returns a single-row Map, list/array returns a List, otherwise the statement is executed only and data is null.

StateWorkFlowController — /stateWorkFlow​

State workflow definition update notification.

notifyUpdate Workflow update notification​

ItemContent
URLGET、POST /api/stateWorkFlow/notifyUpdate/{procDefId}
ParamsprocDefId: path, string, workflow definition (extend) ID.
ReturnsApiResult<String>: publishes the state-workflow upgrade event so all clients refresh, data is a success message string.

SystemInitController — /system/init​

Platform initialization self-inspection: configuration properties, datasources, and SQL scripts.

properties Config properties inventory​

ItemContent
URLGET /api/system/init/properties
ParamsNone
ReturnsApiResult<Map<String,Map<String,String>>>: config key-values grouped by config file source (auth, market, message, oss, package, sc, seata, weixin_work, workflow, default); keys containing password/secret are masked, unresolved values show "未配置" (not configured).

datasource Datasource inventory​

ItemContent
URLGET /api/system/init/datasource
ParamsNone
ReturnsApiResult<List<Map<String,String>>>: merged info list of Spring-managed and dynamically registered datasources (key, class, jdbcUrl, username, masked password, plus dbType, host, port, dbName from the config table).

validate Datasource connectivity check​

ItemContent
URLGET /api/system/init/datasource/validate
Paramskey: query, string, optional, datasource key, defaults to primary.
ReturnsApiResult<Map<String,String>>: connectivity check result: key, connected, jdbcUrl, username, product, driver, durationMs (milliseconds); fails when the datasource is not found.

sql SQL script inventory​

ItemContent
URLGET /api/system/init/sql
ParamsNone
ReturnsApiResult<Map<String,Object>>: db (SQL scripts stored in the database, each with sqlKey, sql, type=db) and file (SQL scripts from files, each with sqlKey, sql, type=file).

UploadController — /upload​

File and configuration upload: attachment upload, config object/JSON persistence, and entity record export as config files.

uploadFile Upload attachment​

ItemContent
URLPOST /api/upload/file
Paramsfile: form-data file field, required, uploaded file.
serviceType: query/form-data, string, file server type.
tableType: query/form-data, string, table type (determines the default save path and the attachment source).
root: query/form-data, string, optional, custom file root directory; the save path is built from it when provided.
isRename: query/form-data, boolean, optional, rename the file, defaults to true.
objectId: query/form-data, string, optional, business object ID.
formIds: query/form-data, string, optional, related form IDs.
genre: query/form-data, string, optional, file genre.
batchNo: query/form-data, string, optional, batch number.
invalidTime: query/form-data, string, optional, invalidation time (datetime format).
validDuration: query/form-data, integer, optional, validity duration in seconds; overrides invalidTime when set.
isThumbnail: query/form-data, boolean, optional, generate a thumbnail.
onlyThumb: query/form-data, boolean, optional, generate the thumbnail only.
dimension: query/form-data, string, optional, thumbnail dimension.
thumbScale: query/form-data, string, optional, thumbnail scale.
appId: query/form-data, string, optional, app ID, defaults to the current app.
tenantCode: query/form-data, string, optional, tenant code, defaults to the current tenant.
ReturnsApiResult<Attachment>: the uploaded attachment info (source set to tableType, storageType set to serviceType).

uploadObject Upload config object​

ItemContent
URLPOST /api/upload/object
Paramsparams: body, Map<String,Object>, required, config content written to the file (Java-serialized object).
fileName: query/form-data, string, required, file name; the .config suffix is appended automatically when missing.
catalog: query/form-data, string, optional, subdirectory under the config root.
ReturnsApiResult<String>: data is the stored file name; an existing file is first backed up by renaming, and overwritten when the backup rename fails.

uploadJson Upload JSON config​

ItemContent
URLPOST /api/upload/json
ParamsJsonData: body, string, required, JSON text (raw request body).
fileName: query/form-data, string, required, file name; the .config suffix is appended automatically when missing.
catalog: query/form-data, string, optional, subdirectory under the config root.
ReturnsApiResult<String>: data is the stored file name; existing files are handled the same way as uploadObject.

uploadModel Export entity record​

ItemContent
URLPOST /api/upload/model/{entityName}/{id}
ParamsentityName: path, string, entity (table) name.
id: path, string, record ID.
fileName: query/form-data, string, required, export config file name; multiple names can be comma-separated.
ReturnsApiResult<NullResult>: queries the record's field values (excluding entity default columns and fields listed in unSaveConfig) and writes each as a .config file; data is empty.
