Files & Attachments (file)

3 controllers with 21 endpoints in total. Controllers marked with ⚙ are design-time APIs.

AttachController — /attach​

Attachment record management: copy, quote, query, update, replace, existence validation, storage migration, deletion and Excel-to-PDF conversion.

copy Copy attachment​

ItemContent
URLPOST /api/attach/copy/{id}
Paramsid: path, string, ID of the attachment to copy.
genre: body, string, optional, business genre tag (written to the new attachment's genre).
name: body, string, optional, new file name (original extension appended automatically).
invalidTime: body, string, optional, invalidation time (DATETIME format).
ReturnsApiResult<Attachment>: data is the new attachment record created by the copy; fails when the attachment or its file is missing.

quote Quote attachment​

ItemContent
URLPOST /api/attach/quote/{id}
Paramsid: path, string, ID of the attachment to quote.
genre: body, string, optional, business genre tag.
name: body, string, optional, new file name (original extension appended automatically).
invalidTime: body, string, optional, invalidation time (DATETIME format).
ReturnsApiResult<Attachment>: data is the new quote attachment record (file path shared with the source attachment, pid pointing to it); fails when the source attachment is missing.

get Get attachment detail​

ItemContent
URLGET /api/attach/get/{id}
Paramsid: path, string, attachment ID.
ReturnsApiResult<Attachment>: data is the attachment record.

image List child attachments​

ItemContent
URLPOST /api/attach/image/{id}
Paramsid: path, string, parent attachment ID (pid).
ReturnsApiResult<List<Attachment>>: data is the list of attachments under that pid (e.g. thumbnails of an image).

update Update attachment​

ItemContent
URLPOST /api/attach/update/{id}
Paramsid: path, string, attachment ID.
body: Map<String,Object>, attachment field name to value mapping (populated onto Attachment fields).
ReturnsApiResult<Attachment>: data is the updated attachment record.

replace Replace attachment​

ItemContent
URLPOST /api/attach/replace/{sourceId}/{targetId}
ParamssourceId: path, string, source attachment ID.
targetId: path, string, target attachment ID.
body: Map<String,Object>, field updates for the target attachment.
ReturnsApiResult<Attachment>: data is the target attachment record (fields updated, source pid inherited and tagged Replace, its ID replaced with the source attachment ID; the source record is kept under a new ID); fails when the source or target attachment is missing.

validate Validate file existence​

ItemContent
URLPOST /api/attach/valid
ParamsattachmentIds: body, string, comma-separated attachment IDs.
ReturnsApiResult<Map<String,Boolean>>: data maps attachment ID to whether its file exists (boolean); fails when the IDs are empty or the attachments do not exist.

updateStorageType Migrate storage type​

ItemContent
URLPOST /api/attach/storage/{type}
Paramstype: path, string, target storage type: local local storage / aliyun Alibaba Cloud OSS.
attachmentIds: body, string, comma-separated attachment IDs.
ReturnsApiResult<Map<String,String>>: data maps attachment ID to a processing message, containing only problem items (file missing, migration failed, storage type unchanged); fails when the IDs are empty or the attachments do not exist.

list List attachments​

ItemContent
URLPOST /api/attach/list
Paramsbody: Map<String,Object>, query conditions and paging params (e.g. ids, pids, batchNo, storageType; paging keys current/pageSize/order, see FileHandler.getAttachments).
ReturnsApiResult<List<Attachment>>: data is the matching attachment list.

pageQuery Page query​

ItemContent
URLPOST /api/attach/pageQuery
Paramscurrent: body, long, page number, defaults to 1.
pageSize: body, int, page size, defaults to 10.
order: body, string, sort (field|direction, | replaced by a space, defaults to create_at desc).
remaining keys: body, used as query conditions.
ReturnsApiPagedResult: data is DataItems<Attachment> (items attachment array + total count), with paging info on the outer envelope.

columnType Column value options​

ItemContent
URLGET /api/attach/column/{type}
Paramstype: path, string, column type: source, storageType (enum values returned directly), type, resolution (distinct values queried from the table).
ReturnsApiResult<List<String>>: data is the list of available values for that column.

remove Delete attachment​

ItemContent
URLDELETE /api/attach/remove/{id}
Paramsid: path, string, attachment ID.
isRemoved: query, boolean, whether to physically delete from the database (true deletes, false marks as deleted).
deleteOss: query, boolean, optional, defaults to false, whether to also delete the OSS object.
ReturnsApiResult<NullResult>: data is empty.

batchRemove Batch delete attachments​

ItemContent
URLPOST /api/attach/remove/{type}
Paramstype: path, string, deletion scope; with batchNo the batch numbers are resolved from the attachment IDs and every attachment of the same batches is deleted.
isRemoved: query, boolean, whether to physically delete from the database.
attachmentIds: body, string, comma-separated attachment IDs.
ReturnsApiResult<NullResult>: deletes the attachments one by one; data is empty; fails when the IDs are empty.

toPdf Convert attachment to PDF​

ItemContent
URLGET /api/attach/toPdf/{id}
Paramsid: path, string, attachment ID; only .xlsx/.xls files are supported.
ReturnsApiResult<String>: data is the attachment ID of the converted PDF; fails when the attachment or file is missing, the format is unsupported, or conversion fails.

CompressController — /pack​

Attachment packaging (zip, split into packages) and compressed-package attachment ID resolution, supporting compression by attachment ID, batch number and thumbnail.

byFileIds Compress by file IDs​

ItemContent
URLPOST /api/pack/by/fileIds
Paramsbody: CompressRequestBody structure: attachmentIds (string, comma-separated attachment IDs), batchNos (string, comma-separated batch numbers), fileName (string, archive file name), serviceType (string, storage service type), genre (string, business genre tag), validDuration (int, validity duration in seconds, invalidation time derived automatically), invalidTime (date, invalidation time), amount (int, max files per archive, system default when omitted), gql (string, gql statement).
ReturnsApiResult<Map<String,Object>>: data contains attachmentIds (list of archive attachment IDs) and batchNo (batch number); fails when compression fails.

byBatchNos Compress by batch numbers​

ItemContent
URLPOST /api/pack/by/batch
Paramsbody: same CompressRequestBody structure as by/fileIds.
ReturnsApiResult<Map<String,Object>>: data contains attachmentIds (list of archive attachment IDs) and batchNo (batch number); fails when compression fails.

downloadFiles Pack or resolve attachments​

ItemContent
URLPOST /api/pack/by/{type}/{column}
Paramstype: path, string, pack to compress / simple to resolve attachment IDs only.
column: path, string, id by attachment ID / batchNo resolves batch numbers from the IDs and expands to all attachments of the same batches.
attachmentIds: body, string, comma-separated attachment IDs.
ReturnsApiResult<List<String>>: data is the attachment ID list (for pack, the archive attachment IDs, file name taken from the current timestamp); throws when attachments are missing or compression fails.

byThumbs Compress thumbnails​

ItemContent
URLPOST /api/pack/by/thumb
Paramsbody: same CompressRequestBody structure as by/fileIds; attachmentIds is resolved by pid into their child attachment (thumbnail) IDs before compressing.
ReturnsApiResult<Map<String,Object>>: data contains attachmentIds (list of archive attachment IDs) and batchNo (batch number); fails when compression fails.

OssController — /oss​

OSS (Alibaba Cloud object storage) management: bucket statistics and dual-side (database vs cloud) file verification as an async task. Registered only when the OSS component is enabled.

stats Bucket statistics​

ItemContent
URLGET /api/oss/stats
ParamsNone
ReturnsApiResult<Map<String,Object>>: data is the OSS bucket statistics (storage usage, file count, etc.); fails when the statistics cannot be fetched.

startVerify Start verify task​

ItemContent
URLPOST /api/oss/start-verify
ParamsNone
ReturnsApiResult<Map<String,Object>>: data contains taskId; verification runs asynchronously, task results are kept for 30 minutes, poll verify-status for progress.

verifyStatus Verify task progress​

ItemContent
URLGET /api/oss/verify-status/{taskId}
ParamstaskId: path, string, verify task ID.
ReturnsApiResult<Map<String,Object>>: data contains status (running/completed/failed), total, checked, existCount, missingCount, results (each item with attachId, name, objectName, type, exists, plus error when the check throws), and errorMessage on failure; fails when the task does not exist or has expired.
