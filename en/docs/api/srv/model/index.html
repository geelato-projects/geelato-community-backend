Data Modeling (model)

7 controllers, 48 endpoints in total. All endpoints in this domain are design-time APIs (@DesignTimeApiRestController), intended primarily for the visual designers.

DevDbConnectController ⚙ — /model/connect​

Design-time management of database connections (ConnectMeta): CRUD, connection testing and dynamic data source refresh.

pageQuery Page query connections​

ItemContent
URLPOST /api/model/connect/pageQuery
ParamsPagination and filter params: see Conventions
ReturnsApiPagedResult<ConnectMeta>: paged list of database connection configurations (connect name, db type, host, port, db name, schema, user name, etc.).

query Query all connections​

ItemContent
URLGET /api/model/connect/query
ParamsPagination and filter params: see Conventions
ReturnsApiResult<List<ConnectMeta>>: list of connection configurations (method signature declares a raw ApiResult).

get Connection detail​

ItemContent
URLGET /api/model/connect/get/{id}
Paramsid: path, string, required, connection ID.
ReturnsApiResult<ConnectMeta>: connection configuration detail (method signature declares a raw ApiResult).

createOrUpdate Create or update connection​

ItemContent
URLPOST /api/model/connect/createOrUpdate
Paramsform: body, ConnectMeta object, required. Common fields: connect name dbConnectName, db type dbType, host dbHostnameIp, port dbPort, database dbName, schema dbSchema, user name dbUserName, password dbPassword.
ReturnsApiResult<ConnectMeta>: first checks duplicates by type+host+port+db name+app+tenant (fails on duplicate); with a non-blank id it updates (schema changes upgrade metadata accordingly), otherwise it creates and immediately refreshes the dynamic data source. Returns the saved connection.

isDelete Delete connection​

ItemContent
URLDELETE /api/model/connect/isDelete/{id}
Paramsid: path, string, required, connection ID.
ReturnsApiResult<NullResult>: fails when the connection is referenced by tables/views/checks; otherwise marks it disabled and soft-deletes. data is empty.

jdbcConnect Test JDBC connection​

ItemContent
URLPOST /api/model/connect/jdbcConnect
Paramsform: body, ConnectMeta object, required; the driver and URL format are resolved from dbType.
ReturnsApiResult<Boolean>: whether a valid JDBC connection can be established.

batchCreate Batch copy connections​

ItemContent
URLPOST /api/model/connect/batchCreate
ParamsappId: body, string, required, target app ID.
connectIds: body, string array, required, source connection IDs.
userName: body, string, required, database user name.
password: body, string, required, database password.
ReturnsApiResult<NullResult>: copies the source connections to new ones (overriding user name, password and app); fails when an identical connection already exists. data is empty.

refresh Refresh one data source​

ItemContent
URLPOST /api/model/connect/refresh/{id}
Paramsid: path, string, required, connection ID.
ReturnsApiResult<Boolean>: whether the refresh succeeded; fails when the connection does not exist or the dynamic data source capability is disabled.

refreshAll Refresh all data sources​

ItemContent
URLPOST /api/model/connect/refreshAll
ParamsNone
ReturnsApiResult<Integer>: number of refreshed data sources; fails when the dynamic data source capability is disabled.

DevTableCheckController ⚙ — /model/table/check​

Design-time CRUD and uniqueness validation of table check constraints (TableCheck).

pageQuery Page query checks​

ItemContent
URLPOST /api/model/table/check/pageQuery
ParamsPagination and filter params: see Conventions
ReturnsApiPagedResult<DataItems>: data is a DataItems (total plus items, the list of check constraint records).

query Query all checks​

ItemContent
URLGET /api/model/table/check/query
ParamsPagination and filter params: see Conventions
ReturnsApiResult<List<TableCheck>>: list of check constraints (method signature declares a raw ApiResult).

get Check detail​

ItemContent
URLGET /api/model/table/check/get/{id}
Paramsid: path, string, required, check constraint ID.
ReturnsApiResult<TableCheck>: check constraint detail (method signature declares a raw ApiResult).

createOrUpdate Create or update check​

ItemContent
URLPOST /api/model/table/check/createOrUpdate
Paramsform: body, TableCheck object, required. Common fields: title title, code code, type type, check clause checkClause, owning table tableId, related column columnId (connectId, tableName, etc. are filled from the owning table).
ReturnsApiResult<TableCheck>: saved with synced set to not-synced, and the entity metadata cache of the owning table is refreshed (method signature declares a raw ApiResult).

isDelete Delete check​

ItemContent
URLDELETE /api/model/table/check/isDelete/{id}
Paramsid: path, string, required, check constraint ID.
ReturnsApiResult<NullResult>: soft-deletes and refreshes the entity metadata cache of the owning table. data is empty.

validate Validate check name​

ItemContent
URLPOST /api/model/table/check/validate
Paramsform: body, TableCheck object, required; tableId and type must not be blank, code is the uniqueness key.
ReturnsApiResult<Boolean>: first checks platform_dev_table_check for an existing record with the same code and type, then switches to the target connection to check the database for a check constraint with the same name; returns true only when neither exists (false when the connection is missing or something exists).

DevTableColumnController ⚙ — /model/table/column​

Design-time CRUD of table columns (ColumnMeta), plus default column templates, select types and name-uniqueness validation.

pageQuery Page query columns​

ItemContent
URLPOST /api/model/table/column/pageQuery
ParamsPagination and filter params: see Conventions
ReturnsApiPagedResult<ColumnMeta>: paged list of columns.

query Query all columns​

ItemContent
URLGET /api/model/table/column/query
ParamsPagination and filter params: see Conventions
ReturnsApiResult<List<ColumnMeta>>: list of columns (method signature declares a raw ApiResult).

get Column detail​

ItemContent
URLGET /api/model/table/column/get/{id}
Paramsid: path, string, required, column ID.
ReturnsApiResult<ColumnMeta>: column detail (method signature declares a raw ApiResult).

createOrUpdate Create or update column​

ItemContent
URLPOST /api/model/table/column/createOrUpdate
Paramsform: body, ColumnMeta object, required. Common fields: column name name, title title, column type type/dataType, owning table tableId, select type selectType, auto add autoAdd/autoName, etc.
ReturnsApiResult<ColumnMeta>: on update, a renamed column is first copied in the database (keeping the old one) and column permissions are adjusted; on create, it is marked not-synced and table default column permissions are reset; when the select type is organization/user with auto-add enabled, related columns are generated automatically. Finally the default view and entity metadata cache are refreshed (method signature declares a raw ApiResult).

insertCommon Copy columns into table​

ItemContent
URLPOST /api/model/table/column/insertCommon
ParamstableId: body, string, required, target table ID.
columnIds: body, string, required, IDs of the columns to copy, comma-separated.
tableName: body, string, read by the code but not used.
ReturnsApiResult<NullResult>: copies existing columns into the target table (skipping same names, marked not-synced) and refreshes the default view and entity metadata cache. data is empty.

isDelete Delete column​

ItemContent
URLDELETE /api/model/table/column/isDelete/{id}
Paramsid: path, string, required, column ID.
ReturnsApiResult<NullResult>: soft-deletes and refreshes the default view and entity metadata cache. data is empty.

queryDefaultMeta Default column templates​

ItemContent
URLGET /api/model/table/column/queryDefaultMeta
ParamsNone
ReturnsApiResult<List<ColumnMeta>>: list of built-in default column templates.

selectType Column select types​

ItemContent
URLGET /api/model/table/column/selectType
ParamsNone
ReturnsApiResult<List<ColumnSelectType>>: selectable data types for columns (group group, label label, value value, database type mysql, disabled flag, default length, value range, etc.).

validate Validate column name​

ItemContent
URLPOST /api/model/table/column/validate
Paramsform: body, ColumnMeta object, required; uses name, tableId, appId, tenantCode.
ReturnsApiResult<Boolean>: checks whether the column name is duplicated within the same table (queries platform_dev_column); true when available.

DevTableController ⚙ — /model/table​

Design-time CRUD of tables (TableMeta) with copy, upgrade, default view and database-driven reset.

pageQuery Page query tables​

ItemContent
URLPOST /api/model/table/pageQuery
ParamsPagination and filter params: see Conventions
ReturnsApiPagedResult<TableMeta>: paged list of tables.

query Query all tables​

ItemContent
URLGET /api/model/table/query
ParamsPagination and filter params: see Conventions
ReturnsApiResult<List<TableMeta>>: list of tables.

get Table detail​

ItemContent
URLGET /api/model/table/get/{id}
Paramsid: path, string, required, table ID.
ReturnsApiResult<TableMeta>: table detail.

createOrUpdate Create or update table​

ItemContent
URLPOST /api/model/table/createOrUpdate
Paramsform: body, TableMeta object, required. Common fields: entity name entityName, title title, connection connectId, table type tableType, source sourceType, etc. (tableSchema and dbType are filled from the connection).
ReturnsApiResult<TableMeta>: on create, marks not-synced, initializes table default permissions and creates default columns for non-third-party sources; on update, an entity-name change backs up the old table and renames it in the database (adjusting permissions and refreshing the default view). Finally the entity metadata cache is refreshed; returns the saved table (signature declares ApiResult<?>).

copy Copy table​

ItemContent
URLPOST /api/model/table/copy
Paramsid: body, string, required, source table ID.
entityName: body, string, required, entity name of the new table.
title: body, string, optional, title of the new table.
connectId: body, string, optional, connection of the new table.
tableComment: body, string, optional, comment of the new table.
appId: body, string, optional, app ID.
tenantCode: body, string, optional, tenant code.
ReturnsApiResult<TableMeta>: copies the source table and its columns into a new table (source type reset to manual creation), initializes default permissions and refreshes the entity cache.

upgradesTable Upgrade table structure​

ItemContent
URLPOST /api/model/table/upgradesTable
ParamstableId: body, string, required, target table ID.
columnNames: body, string, required, comma-separated upgrade-template column names.
upgradeType: body, string, optional, contains app to enable cross-app and workflow to enable cross-workflow.
ReturnsApiResult<NullResult>: adds the upgrade-template columns missing from the table, updates the cross-app/cross-workflow flags per upgradeType and refreshes the entity cache; data is empty on success (signature declares ApiResult<?>).

isDelete Delete table​

ItemContent
URLDELETE /api/model/table/isDelete/{id}
Paramsid: path, string, required, table ID.
ReturnsApiResult<NullResult>: soft-deletes (the database table is renamed with a _d timestamp suffix and the title/comment get a "deleted" prefix) and removes the entity metadata cache; data is empty.

queryDefaultView Default view SQL​

ItemContent
URLGET /api/model/table/queryDefaultView/{entityName}
ParamsentityName: path, string, required, entity name.
ReturnsApiResult<String>: the default view SQL (viewConstruct) generated from the entity columns.

resetDefaultView Reset default view​

ItemContent
URLPOST /api/model/table/resetDefaultView
Paramsform: body, TableMeta object, required; entityName must not be blank (matched together with id and connectId).
ReturnsApiResult<NullResult>: rebuilds or updates the default view for the matched tables. data is empty.

resetModelFormTable Reset table from database​

ItemContent
URLPOST /api/model/table/reset/{tableId}
ParamstableId: path, string, required, table ID; disabled tables cannot be reset.
ReturnsApiMetaResult<NullResult>: syncs the table definition from the actual database structure (updates the table info and resets columns and foreign keys; when the table no longer exists in the database it is soft-deleted). data is empty (with the extra meta).

validate Validate entity name​

ItemContent
URLPOST /api/model/table/validate
Paramsform: body, TableMeta object, required; uses entityName, connectId, appId, tenantCode.
ReturnsApiResult<Boolean>: checks whether the entity name is duplicated within the same connection; when conflict detection is enabled and the name clashes with a loaded Java built-in entity, a failure message is returned directly.

DevTableImportController ⚙ — /model/table/import​

Raw-JSON import of tables/columns/checks, either preserving external primary keys or letting the system generate new ones.

importRaw Import preserving IDs​

ItemContent
URLPOST /api/model/table/import/preserveId
ParamsbodyJson: body, string (raw JSON text), required, the import JSON must contain a table (object) and a columns (array) node, with checks (array) optional; every record in all three parts must carry an id.
ddl: query, boolean, optional, default true, whether to create/update the database table structure right after a successful import.
ReturnsApiResult<Map<String,Object>>: import counts tables/columns/checks; all records are saved as-is under their external IDs (forceId preserves the primary key), audit fields are overwritten with the current user/tenant/time, and the entity metadata cache is refreshed afterwards.

importCreate Import with new IDs​

ItemContent
URLPOST /api/model/table/import/create
ParamsbodyJson: body, string (raw JSON text), required, the import JSON must contain a table (object) and a columns (array) node, with checks (array) optional; every record in all three parts must NOT carry an id.
ddl: query, boolean, optional, default true, whether to create/update the database table structure right after a successful import.
ReturnsApiResult<Map<String,Object>>: import counts tables/columns/checks; all records are saved with new system-generated IDs, audit fields are overwritten with the current user/tenant/time, and the entity metadata cache is refreshed afterwards.
