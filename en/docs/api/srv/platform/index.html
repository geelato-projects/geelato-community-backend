Apps & Platform Config (platform)

13 controllers, 80 endpoints in total. Endpoints marked with ⚙ are design-time APIs.

AppController — /app​

App registration and version package import, filtering visible apps by user identity, and app page permission queries.

pageQuery Paged query​

ItemContent
URLPOST /api/app/pageQuery
ParamsPagination and filter params: see Conventions
ReturnsApiPagedResult: data is a page of apps (App).

query List query​

ItemContent
URLGET /api/app/query
ParamsPagination and filter params: see Conventions
ReturnsApiResult<List<App>>: list of apps.

queryByUser Query apps by user​

ItemContent
URLGET /api/app/queryByUser
ParamstenantCode: query, string, required, tenant code.
userId: query, string, optional, user ID; defaults to the current logged-in user.
ReturnsApiResult<List<Map<String,Object>>>: data is the list of apps visible to the user, filtered by user type: employees/virtual employees only see normal apps (inside or in-out), tenant admins and system accounts see normal and platform apps, external users only see normal apps marked outside.

get Get details​

ItemContent
URLGET /api/app/get/{id}
Paramsid: path, string, app ID.
ReturnsApiResult<App>: app details.

createOrUpdate Create or update​

ItemContent
URLPOST /api/app/createOrUpdate
Paramsform: body, App entity; non-empty id updates, empty id creates.
useType: query, string, optional; when set to import the import flow runs (requires non-empty form.id, imports the app by its existing ID).
ReturnsApiResult<App>: the saved or imported app.

isDelete Delete app​

ItemContent
URLDELETE /api/app/isDelete/{id}
Paramsid: path, string, app ID.
ReturnsApiResult<NullResult>: data is empty; fails if the app does not exist (soft delete).

validate Validate uniqueness​

ItemContent
URLPOST /api/app/validate/{type}
Paramstype: path, string, check type: code checks app code availability, id checks whether the app ID already exists.
form: body, App entity, provides the code, id, tenantCode to validate.
ReturnsApiResult<Boolean>: true means available (code not taken or ID not present); fails when type is invalid.

queryPermissionByPage App page permission query​

ItemContent
URLGET /api/app/queryPermissionByPage
ParamsappId: query, string, optional, filter by app.
tenantCode: query, string, optional, filter by tenant.
type: query, string, optional, permission type.
treeId: query, string, optional, app page tree node ID.
ReturnsApiResult<List<Map<String,Object>>>: data is a list of page permission records (permission ID, name, code, type, object, rule, and owning page tree node ID).

queryRolePermissionByPage Role page permission query​

ItemContent
URLGET /api/app/queryRolePermissionByPage
ParamsappId: query, string, optional, filter by app.
roleId: query, string, optional, role ID; multiple IDs comma-separated.
type: query, string, optional, permission type.
tenantCode: query, string, optional, filter by tenant.
ReturnsApiResult<List<Map<String,Object>>>: data is a list of role-to-page-permission records (role, permission, and owning app).

upload Upload app package​

ItemContent
URLPOST /api/app/upload/{fileId}
ParamsfileId: path, string, attachment ID of the uploaded app package (.gdp archive).
ReturnsApiResult<App>: data is the imported/updated app; the archive must contain a .gdp descriptor (source app ID, name, code, version); fails when the file is missing or cannot be parsed.

BizDataController — /bizData​

Batch transfer of business data ownership: rewrites creator and other ownership fields across entities.

changeOwner Batch transfer ownership​

ItemContent
URLPOST /api/bizData/changeOwner
ParamsentityIdMap: body, Map<String,List<String>>, keys are entity names, values are the lists of primary key IDs to transfer for each entity.
owner: query, string, required, target owner user ID.
ReturnsApiResult<Map<String,Integer>>: data maps each entity to the number of updated records. Admins can transfer any non-platform entity's data; non-admins can only transfer records they created, and the entity must contain ownership fields; platform entities (platform catalog/entity-name/table-name prefix) cannot be transferred; the whole request fails with deny details when unauthorized records, invalid entities, or an unknown user are involved.
