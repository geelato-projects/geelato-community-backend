AuthCodeController — /code​

Verification code generation and delivery: generates a 6-digit code by verification method (SMS/email), sends the message and caches the code in Redis.

generateUser Generate user auth code​

ItemContent
URLPOST /api/code/generate/user
Paramsbody: Map<String,Object>, fields mapped onto AuthCodeParams: userId (user ID, the user must exist), action (business action, e.g. VALIDATEUSER), validType (verification method: mobile/email), prefix (mobile prefix), validBox (mobile number or email; backfilled from the user profile when action is VALIDATEUSER), authCode (verification code).
ReturnsApiResult<NullResult>: data is empty; on failure msg carries the error.

generateAuth Generate auth code​

ItemContent
URLPOST /api/code/generate/auth
Paramsbody: Map<String,Object>, fields as above; sends the code directly to validBox (mobile/email) according to validType and caches it.
ReturnsApiResult<NullResult>: data is empty; on failure msg carries the error.
