Organization & Users

This page covers 6 entities across organizations, companies, users, administrative divisions and tenants. User is the platform account principal; Org forms the organization tree; Company carries legal-entity company information and links to organizations; Tenant/TenantSite carry multi-tenancy and site configuration. For the read-side view of organizations and users in the security contract, see Security Contract Overview.
