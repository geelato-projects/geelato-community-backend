Platform Entity Index

This page is the master index of all runtime entities in the platform: it answers "which entity metadata actually exists in the platform". Entity definitions are spread across modules — core entities are centralized in geelato-meta, while feature modules (business alerting, business exceptions, mail, platform built-in capabilities) define their own entities. Registration is identical everywhere: they all live under the cn.geelato package and are auto-registered by the MetaManager startup scan (see Overview).

Entities not included in this index:

  • Framework meta-model classes (TableMeta, ColumnMeta, TableView, TableCheck, TableForeign, ConnectMeta in geelato-core) — although also annotated @Entity, they carry the definition of metadata itself, mapped to the six platform_dev_* designer tables; see Metadata Overview.
  • The MqlTest* sample models of geelato-maintenance (MqlTestUser/MqlTestOrder/MqlTestOrderItem etc.) — MQL test fixtures, not runtime entities.
