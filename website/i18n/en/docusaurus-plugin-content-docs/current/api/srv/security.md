## AuthCodeController — `/code`

Verification code generation and delivery: generates a 6-digit code by verification method (SMS/email), sends the message and caches the code in Redis.

### generateUser Generate user auth code

| Item | Content |
| --- | --- |
| URL | `POST /api/code/generate/user` |
| Params | body: `Map<String,Object>`, fields mapped onto `AuthCodeParams`: `userId` (user ID, the user must exist), `action` (business action, e.g. `VALIDATEUSER`), `validType` (verification method: mobile/email), `prefix` (mobile prefix), `validBox` (mobile number or email; backfilled from the user profile when `action` is `VALIDATEUSER`), `authCode` (verification code). |
| Returns | `ApiResult<NullResult>`: `data` is empty; on failure `msg` carries the error. |

### generateAuth Generate auth code

| Item | Content |
| --- | --- |
| URL | `POST /api/code/generate/auth` |
| Params | body: `Map<String,Object>`, fields as above; sends the code directly to `validBox` (mobile/email) according to `validType` and caches it. |
| Returns | `ApiResult<NullResult>`: `data` is empty; on failure `msg` carries the error. |
