# 系统功能

> **说明：本节介绍统一认证中心管理端自带的功能菜单，按管理端左侧导航的实际结构逐一说明各功能的用途。**
>
> 集成方阅读本节可以了解认证中心"开箱即用"提供了哪些能力、各自解决什么问题；运维管理员则可以直接按菜单对号入座。功能如何通过开放 API 对接，请参阅各集成板块文档。

## 功能总览

认证中心管理端菜单共六个分组：

| 菜单分组 | 包含功能 | 一句话用途 |
| --- | --- | --- |
| **客户端管理** | 客户端 | 注册与维护 OAuth2 接入应用（client_id / 密钥 / 回调地址） |
| **身份管理** | 组织管理、用户管理、角色管理 | 维护组织架构、账号与角色，是身份与授权数据的源头 |
| **权限管理** | 菜单管理、权限管理 | 登记下游应用的菜单与五类权限点，供角色授权与下发 |
| **认证管理** | 社交登录、令牌查询 | 配置第三方登录渠道；联调时查询令牌详情 |
| **业务审计** | 操作记录、会话管控 | 审计事件检索与防篡改校验；在线会话管控与强制下线 |
| **系统管理** | 字典管理、应用配置 | 系统级字典与运行参数的日常维护 |

## 客户端管理

管理接入认证中心的**客户端（应用）**，是 OAuth2 接入的前置条件：

- 注册新客户端，分配 `client_id` 与 `client_secret`
- 配置回调地址、授权类型、令牌有效期等接入参数
- 支持重置客户端密钥

业务系统要使用 [OAuth2 协议接入](oauth2-integration.md)（授权码模式或机器对机器），必须先在此登记为客户端；[Lite 轻量接入](lite-login-integration.md) 同样依赖客户端配置。

## 身份管理

### 组织管理

维护认证中心的**组织架构**：按公司 / 部门层级维护组织树，用户归属到具体部门。组织数据是用户主数据的骨架，也是部门级授权（部门绑定角色）的基础。需要同步组织数据到业务系统时，参见[数据集成](data-integration.md)。

### 用户管理

维护**用户账号的全生命周期**：新增 / 编辑账号、启用停用、重置密码，并为用户分配所属部门与角色。用户登录后能否获得哪些权限，取决于这里分配的角色与部门。

### 角色管理

维护**角色**并完成授权绑定：一个角色可以同时绑定用户、菜单与权限点。角色是"人"与"权限"之间的桥梁——权限下发时按用户生效权限计算，而生效权限正是由角色聚合而来。权限如何下发到业务系统，参见[权限接入](permission-integration.md)。

## 权限管理

### 菜单管理

为**下游应用注册菜单树**：菜单分目录 / 菜单 / 按钮三种类型，可挂接权限编码。菜单数据有两个用途：一是作为角色授权的对象（角色可绑定哪些菜单），二是随用户生效权限下发给业务系统，供其渲染动态菜单。管理集成方式下，集成方也可通过开放 API 读取菜单数据，参见[管理集成](open-api-management.md)。

### 权限管理

登记与管理**权限点**。权限点分五类，与用户生效权限的五个分组一一对应：

| 类型 | 含义 |
| --- | --- |
| `dp` | 数据权限（Data Permission） |
| `mp` | 模型权限（Model Permission） |
| `cp` | 字段权限（Column Permission） |
| `ep` | 元素权限（Element Permission，页面按钮等元素级控制） |
| `fp` | 功能权限（Function Permission，接口 / 操作级控制） |

权限点的类型取值由系统白名单保证，字典中仅维护其展示元数据。业务系统通过[权限接入](permission-integration.md)按 fail-closed 原则消费下发结果。

## 认证管理

### 社交登录

按租户配置**第三方登录渠道**（微信、企业微信、飞书、钉钉）的应用凭证与回调参数。配置完成后，统一登录页与 Lite 登录即可展示对应的第三方登录方式。接入方式参见[Lite 轻量接入](lite-login-integration.md)。

### 令牌查询

粘贴 `access_token` 即可查询该令牌的详情：令牌存储模式（memory / redis）、所属客户端、对应登录用户、有效期等。主要用于联调与排障——例如确认令牌是否签发成功、归属哪个应用与用户。

## 业务审计

### 操作记录

查询认证中心的**安全审计事件**：支持按分类、结果（成功 / 失败 / 拒绝 / 异常）、操作者、关键字组合检索，并可查看事件明细。审计事件以哈希链方式记录，提供**完整性校验**入口，可发现记录是否被篡改，满足安全审计要求。

### 会话管控

查看与管理**在线会话**：可全量列出当前在线会话，或按登录名查询某用户的全部会话；支持将某登录名的会话**整组踢出**，或按设备类型**踢出指定设备**。用于账号异常时的应急下线与会话治理。

## 系统管理

### 字典管理

维护认证中心的**字典与字典项**：内置权限类型（`permission_type`）、组织类型（`org_type`）、菜单类型（`menu_type`）三个内置字典，并支持新建自定义字典供业务扩展。内置字典受保护规则约束（禁删、编码禁改、受控字典禁新增项），管理端各下拉（如权限类型、组织类型）由此驱动。

### 应用配置

维护认证中心的**运行参数**（`app_config` 键值配置），支持在线修改并热更新生效，无需重启服务。用于调整认证中心各模块的运行时开关与参数。

## 功能与集成板块的对应关系

管理端维护的是"源数据"，业务系统通过集成板块消费这些数据：

| 管理端功能 | 产出的数据 | 集成方如何消费 |
| --- | --- | --- |
| 客户端管理 | OAuth2 客户端凭证 | [OAuth2 协议接入](oauth2-integration.md)、[Lite 轻量接入](lite-login-integration.md) |
| 组织 / 用户 / 角色 | 身份主数据 | [数据集成](data-integration.md)（开放 API / SDK / SQL 脚本） |
| 菜单 / 权限点 + 角色授权 | 用户生效权限 | [权限接入](permission-integration.md)（五类权限下发） |
| 社交登录 | 第三方登录渠道 | 登录集成两种方式的第三方登录入口 |
| 操作记录 / 会话管控 | 审计与会话治理 | 管理端自带能力，保障运行安全 |
| 字典 / 应用配置 | 系统级配置 | [管理集成](open-api-management.md)（开放 API 只读字典等） |
