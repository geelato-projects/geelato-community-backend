# Geelato Workflow 工作流

geelato-workflow 是独立部署的工作流服务（默认端口 8089），基于 Activiti 引擎，提供流程定义、审批流转等能力；业务系统通过 API 接入，拥有工作流专用的数据源与运行参数。
